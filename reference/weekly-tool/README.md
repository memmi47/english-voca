# 학원 원서 어휘 캐치업

한 주에 학원에서 받는 원서 한 권을 교재로 사용합니다. 책을 읽는 시간 중 하루 10~15분을 어휘 확인과 인출에 배정합니다. 아들과 딸의 앎·모름, 복습일, 연속 정답, 진단 결과는 각각 기록합니다.

## 처음 실행

Mac이나 PC에서 ZIP을 풀고 터미널로 해당 폴더를 엽니다. Python 3.10 이상과, 사진을 처리할 경우 영어 데이터가 설치된 Tesseract가 필요합니다. 교정 텍스트만 넣을 때는 Python 표준 라이브러리만 사용합니다.

Mac에서 Homebrew를 사용하는 경우 사진 OCR을 다음 명령으로 준비할 수 있습니다.

```sh
brew install tesseract
python3 app.py
```

브라우저에서 [http://127.0.0.1:8765](http://127.0.0.1:8765)를 엽니다. 같은 집 Wi-Fi의 iPad에서 접속하려면 Mac에서 `python3 app.py --host 0.0.0.0 --pin 가족이정한6자이상코드`로 실행하고 iPad의 Safari에서 `http://Mac의-사설-IP:8765`를 엽니다. 가족 내부에서 사용합니다. LAN과 iPad 동작은 별도 확인이 필요합니다.

종료는 터미널에서 Ctrl+C입니다. `family_state.sqlite3`와 `audio/`를 함께 보관하면 학습 상태와 음원 등록을 다시 사용할 수 있습니다. 가족이 실제 사용하기 전에 별도 파일로 테스트하려면 `python3 app.py --db demo.sqlite3`를 사용합니다.

## 한 주 운영

| 시점 | 부모 작업 | 아이 활동 |
|---|---|---|
| 책 받은 날 | 첫 장 전체와 무작위 10쪽을 골라 총 약 15~20쪽을 JPG 또는 PNG로 촬영. 판본마다 고정된 책 ID로 한 번 등록 | 그날 분량에서 모르는 단어와 들으면 아는 단어를 가볍게 확인 |
| 등록 직후 | OCR 원문을 확인하고 눈에 띄는 오류를 수정. 아이별로 10~15개 체크, 같은 철자의 뜻이나 활용형은 문장 확인. 새 단어는 뜻 입력 | 학습 전 부담을 확인 |
| 월~수 | 같은 책을 두고 사전학습 10~15분. 책 수령일이 다르면 이후 3일에 배치 | 소리 → 장면·그림 → 문장. 책에서 다시 찾기 |
| 읽는 날 | 이용할 수 있는 정식 오디오북이 있으면 함께 재생 | 듣고 읽기, 이야기 질문에 말로 답하기 |
| 주말 | 직접 떠올린 단어의 앎·모름을 카드 기록에서 표시. 다음 주에 새 책 표본을 확인 | 배운 문장과 이야기 다시 보기 |
| 월 1회 | ‘누적 T1 인쇄’에서 아이별 최신 소책자를 인쇄 | 짧은 복습 |

부모 작업 목표는 촬영·입력 4분, OCR 결과의 의심 부분 검수 2분, 두 아이 선택 약 2분씩입니다. OCR 대기 시간과 아이별 실제 사용 시간을 따로 재어 10분 목표를 검증합니다. 페이지가 흐리면 JPG로 다시 촬영하거나 교정 텍스트 입력을 사용합니다. HEIC는 JPG/PNG로 변환해 넣습니다.

표본 입력에는 실제 인쇄 쪽 번호가 보이도록 파일명을 붙입니다. 사진 한 장에 한 쪽을 담습니다. 텍스트 모드는 쪽 사이에 독립된 줄 `===`를 넣습니다. 분석은 현재 표본의 관찰치입니다. 줄바꿈을 넘는 문장도 읽되, OCR의 구두점 오류나 그림 속 글자는 교정합니다. 같은 판본을 같은 ID로 재처리하면 표본을 교체해 누적 횟수를 다시 계산합니다.

책 목록을 미리 확보하면 표본을 함께 준비해 `python3 batch.py manifest.json`으로 등록할 수 있습니다. 책 제목만으로 본문 어휘를 확정할 수 없으므로 제목과 표본 확보 가능 여부를 학원에 함께 확인합니다. 다음 예에서 경로는 manifest 파일 위치 기준입니다.

```json
[
  {"id":"GS-01","title":"학원 책 제목","pages":[
    {"page":"5","file":"samples/GS-01/005.jpg"},
    {"page":"8","file":"samples/GS-01/008.txt"}
  ]}
]
```

## 후보와 복습의 처리 방식

- 정확히 맞는 형태와 구동사를 먼저 찾습니다. 표본에 나온 형태와 문장은 후보에서 그대로 확인할 수 있습니다. 형태가 추정되거나 문맥에 따라 여러 뜻이 가능한 행은 직접 확인하도록 체크를 비워 둡니다. 제목·주제 어휘를 포함해 부모가 선택을 조정합니다.
- 누적 권수는 책 ID별로 집계합니다. 형태가 불확실하거나 여러 원형에 연결되는 표현은 부모가 그 문맥에서 확인한 뒤 집계합니다. 고유명사는 대문자 위치와 일부 등장인물 이름을 이용해 추정합니다. 문장 첫머리나 OCR 오류에서 생기는 누락은 부모 검수로 보완합니다.
- T1은 일반 고빈도이면서 아이가 모르는 어휘 또는 관찰 3권 이상입니다. 지정 T2는 관찰 2권부터 T1입니다. 어느 조건에도 해당하지 않는 단어가 한 권에서 관찰되면 T3입니다. 두 권에서 관찰된 비장르 단어는 관찰 중으로 두고 세 번째 권을 기다립니다. 이미 편입해 배운 T1은 누적 복습 목록에서 계속 볼 수 있습니다.
- 주간 추천은 T1·T2 예상 순위, 그 주 등장 횟수, 누적 권수, 일반 빈도 순으로 검토합니다. 제목·이해 필수 여부는 부모가 문맥으로 판단합니다. 별도 학습 목록의 정렬 기준은 누적 권수, 일반 빈도, 이야기 이해 필수 여부입니다.
- 현재 초기 500개는 빈도 근거가 있는 첫 뜻 카드입니다. 새로 외울 500개로 간주할 필요는 없습니다. 실제로 모르는 카드만 T1 신규 대상으로 사용합니다. 요청하신 강등 7개는 초기 500개에서 뺐고, 본문에서 발견되면 일반 전이 조건으로 다시 판단합니다.
- 복습일은 성공 후 1·3·7·14·30일로 늘리고, 실패하면 연속 정답 수를 0으로 되돌려 다음 날 확인합니다. T3, 패턴, 보류 트랙은 장기 복습일이 생기지 않습니다. 하루 10~15분 안에서 신규는 최대 8~10개, 복습은 20~30개를 상한으로 삼습니다. 그 주 신규 카드 10~15개는 월~수에 나누면 하루 평균 약 4~5개입니다. 같은 날 반복해도 장기 학습 성공을 여러 번 기록하지 않도록 운영합니다.

## 듣기 진단

시작 시 한 번, 이후 분기별로 진행합니다. 150문항은 기존 P1 50, P2 60, P3 40입니다. 그림으로 구별할 수 있는 후보 안에서 주제를 순환해 뽑았습니다. 주제별 그림 후보 풀이 달라 특히 P3은 완전 균등하지 않습니다. 4지선다의 보정식은 `(정답률−0.25)/0.75`입니다. 90% 판정의 최소 정답은 P1 47/50, P2 56/60, P3 37/40입니다. 기준을 충족하면 구간 ‘앎’을 추정으로 기록하고, 해당 구간에서도 틀린 문항은 모름으로 기록합니다. 아이가 직접 답한 뒤 오류를 확인하면 추정을 덮어씁니다. 두 아이의 점수는 실행 터미널에 표시된 보호자 코드로 각각 확인합니다. 아이가 사용하는 브라우저에서는 보호자 화면을 열지 않습니다.

- 등록한 음원이 자동으로 재생됩니다. ‘소리 켜고 시작’ 버튼으로 브라우저의 재생을 시작합니다. 재생 실패 시 해당 문항을 유지하고 다시 듣습니다.
- 음성 검수 화면에서 파일을 듣고 카드별로 체크합니다. 150개 모두 등록하면 본 진단을 시작할 수 있습니다. 10문항 미리보기는 기기 발음으로 화면을 살펴볼 수 있고 기록을 남기지 않습니다.
- 듣고 그림을 고르는 검사는 문맥 어휘와 문자 해독을 직접 측정하지 않습니다. 150문항을 한 번에 처리하기 어려우면 50문항마다 쉬고 같은 브라우저 탭에서 이어갑니다. 탭을 닫으면 미제출 답안은 사라집니다. 그림 선택지가 아이에게 명확한지는 실제 시행 전에 살펴보세요.

## 소책자와 성과 판정

주간 소책자는 저장한 팩에서 자동으로 생성됩니다. T1·T2 카드에는 책의 문장, 핵심 뜻 하나, 삽화 또는 스케치 칸, ‘들으면 앎 / 읽으면 앎’ 체크 칸을 둡니다. 철자 대상만 ‘쓸 수 있음’을 추가합니다. T3 및 두 권 관찰 항목은 아래 한 번 보기 목록에, 말장난은 별도 해독 코너에 배치합니다. 인쇄 화면의 ‘인쇄 또는 PDF 저장’을 사용합니다.

쪽당 모르는 단어 수는 중복을 포함한 읽기 토큰 수로 기록합니다. 56단어 페이지의 95%는 미지 토큰 약 2.8개입니다. **쪽당 3개는 운영상 근사치**이며, 56단어에서 정확히 95% 이상을 충족하려면 정수 기준 2개 이하입니다. ‘미확인’, ‘고유명사 추정’, ‘진단 구간 추정 앎’은 확인된 앎과 별도로 보며, 미확인을 앎으로 더하지 않습니다. 사전학습 페이지와 다른 쪽을 성과 확인용으로 남겨 두고, 한 주에 같은 방식으로 표본을 기록합니다.

| 아이·주차 | 쪽·단어 수 | 실제 모름 수 | 이야기 질문 | 학습 시간 | 주간 거부 |
|---|---|---:|---|---:|---:|
| 각자 기록 | 책 ID / 쪽 / 토큰 수 | 읽다가 막힌 단어 수 | 사실·원인·다음 행동 각 1문항, 0~3점 | 분 | 횟수 |

4주 내 쪽당 3개 이하, 8주 내 2개 이하를 목표로 봅니다. 미지어가 목표 이하인데 세 문항 이해가 개선되지 않으면 같은 수준의 짧은 문단을 먼저 직접 읽고, 비슷한 문단을 들어 본 뒤 각각 말로 설명하게 합니다. 듣기가 뚜렷이 나으면 소리·철자 대응, 불규칙 과거형, 소리 내 읽기 비중을 늘립니다. 두 조건이 모두 어렵다면 긴 문장과 사건 연결 표현을 짧게 나눕니다. 하루 15분을 넘거나 주 2회 이상 거부 반응이 나타나면 먼저 신규 단어를 줄입니다. 실제 학습 시간과 이해 지표는 이 표로 별도 기록합니다.

## 현재 상태

원서 본문과 두 아이의 읽기·듣기 상태는 아직 등록되지 않았습니다. 신규 후보와 시리즈 말장난 출현을 실제 책으로 확정해야 합니다. 검수 음원은 초기값 0개입니다. 소책자의 삽화는 제공한 그림 기호가 있는 일부 단어에 표시되며, 나머지는 장면 그림 칸을 제공합니다. 소책자에 실물 책 문장이 필요한 경우 그 주 표본이 있어야 채워집니다.

## 선정 자료와 발음 표기

- 고빈도 자격은 원본에 기록한 NDL 1.1, NGSL 1.2, Cambridge YLE 2025의 등재와 순위를 이어받았습니다. [New Dolch List](https://www.newgeneralservicelist.com/new-dolch-list) · [NGSL](https://www.newgeneralservicelist.com/new-general-service-list) · [Cambridge YLE Wordlists](https://www.cambridgeenglish.org/images/506166-starters-movers-flyers-word-list-2025.pdf)
- 국내 과정은 SLP의 파닉스·사이트워드와 POLY Wordit의 교재 연동·누적 복습을 참고했습니다. 원본이 인용한 POLY ECP7 개별 단어의 근거는 비공식 공개 학습기록입니다. 기관별 공식 필수 단어표는 확인되지 않았습니다. [서강 SLP 공식 교육과정](https://beta.slp.ac.kr/curriculum/program/immersion) · [POLY Wordit 공식 소개](https://www.polyinspiration.com/news_detail?idx=42) · [POLY ECP7 공개 학습기록](https://sinmolnam.tistory.com/60)
- 초기 500개에는 미국식 IPA 참고값 500개와 한글 근사 표기 108개가 있습니다. 전체 카드에서는 IPA 6,130개와 한글 근사 표기 120개입니다. 미국식 IPA 자동 추출은 Flite 사전 및 발음 규칙을 사용했습니다. 표기는 단어를 단독으로 읽는 참고값이며, 일부 항목은 문맥별 발음과 다를 수 있습니다. 한글 표기는 소리를 대략 짚는 용도입니다. 온라인 학습은 별도로 검수한 음원에 의존합니다. [Flite 프로젝트](https://github.com/festvox/flite)

`Demo_Sample.txt`는 실행 흐름을 확인하기 위한 자작 문장입니다. 학원 책과 독립된 데모 DB에서만 사용하세요. 단계별 검증 상태는 `Validation.md`에 있습니다.
