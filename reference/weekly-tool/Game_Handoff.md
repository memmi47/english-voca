# Fable·Astra용 게임 제작 자료

## 전달 목적

학원에서 매주 받는 Geronimo Stilton 수준의 원서를 읽는 데 필요한 어휘를 10~15분 안에 보완하는 가족용 게임입니다. 자료에는 합의된 학습 요구, 실행 도구와의 데이터 연결, 비교 서비스 리서치를 담았습니다. Fable과 Astra가 테마, 실제 기획, 인터랙션, 구현, 테스트 계획을 결정합니다.

## 변경할 수 없는 학습 요구

| 항목 | 요구 |
|---|---|
| 학습 단위 | 원형은 여러 책의 등장 집계에 사용하고, 카드에는 책에 실제로 등장한 형태와 뜻 하나를 제시합니다. |
| 주간 투입 | 부모가 검수한 아이별 10~15개. 월~수에 나누어 사전학습하고, 현재 원서에서 같은 표현을 확인합니다. |
| 소리 | 학습 단어 등장마다 자동으로 발음합니다. 다시 듣기, 중복 재생 방지, 무음 실패 복구가 필요합니다. |
| 순서 | 소리, 그림·장면, 문맥. 추상어·기능어·구동사는 문맥으로 가르칩니다. 기능어 121개는 읽기 트랙입니다. |
| 과제 | 기억에서 답을 꺼내는 활동을 사용합니다. 구체 명사 그림 매칭, 동작은 TPR, 소리는 효과음, 감정은 표정·장면, 불규칙 과거는 기본형 짝짓기입니다. |
| 깊이 | 1 소리→그림, 2 단어→뜻, 3 문장 빈칸, 4 철자. 설정된 깊이까지만 진행합니다. T3 최대 2, T2 최대 3. 철자는 선별한 T1 대상입니다. |
| 스테이지 | 한 장면 안에 8~10개. scared, frightened, terrified 같은 유사어는 다른 스테이지에서 처음 만나고, 나중에 강도 비교로 연결합니다. |
| 복습 | T1·T2만 장기 복습. 정답 시 1·3·7·14·30일 순서. 신규 8~10개와 복습 20~30개는 상한이고, 전체 15분을 넘기지 않습니다. |
| 남매 | 프로필·진도·학습 결과 분리. 협동 목표는 가능. 점수 비교 화면은 금지합니다. |
| 말장난 | 22개 후보 표. 확인 대기 항목과 자작 예시를 구분하고, mouse/cheese와 결합한 단어를 나눠 읽는 규칙을 연습합니다. 개별 장기 암기는 제외합니다. |

## 데이터 연결

- `vocabulary.json`의 `lemmas`, `cards`, `pending`, `diagnostic`이 기준 데이터입니다. `lemma_link`를 기준으로 권수·빈도를 공유하고, `card_id` 기준으로 아이별 인출과 음원을 저장합니다. 처음 투입할 목록은 `starter_order`가 1~500인 카드입니다.
- `app.py`의 학습 기록 내보내기로 아이별 승인 팩, 원형별 관찰 수치, 학습 상태, 현장에서 등록한 카드, 검수 음원 파일명을 얻습니다. 로컬 음원은 `audio/`에 있습니다. 정적 JSON의 `audio_checked`는 초기값이며 실제 여부는 등록 목록으로 갱신합니다. 승인 팩의 `tier`, `depth_target`, `context`, `page`를 우선 사용합니다.
- `card_states` 값 순서는 `[known, origin, due, streak]`입니다. `corpus` 값 순서는 `[book_count, token_count, first_seen_book]`입니다. `진단 구간 추정`은 아이가 직접 해당 카드에 답한 결과와 구분합니다.
- 원본 XLSX와 개편된 XLSX는 검토용입니다. 주간 팩과 실시간 상태는 로컬 SQLite에 누적합니다. 공개 배포 전에 실제 본문 사용 범위, 음원 권한, 자산의 라이선스를 확인합니다.

## 음성과 인수 확인

1. `present`, `read`, `live`, `wind`, `tear`, `close`, `record`는 뜻·형태별로 다른 음원 키를 부여합니다. 본문에서 의미를 분명히 한 뒤 목표 단어와 문장 음성을 별도 관리하고, 사람이 실제로 들어 검수합니다. 강세 참고 칸은 음성 파일 승인 상태와 구별합니다.
2. iPad Safari에서 사용자가 소리 켜고 시작 버튼을 누른 다음, 각 카드 전환과 뒤로 돌아오기에서 음성이 재생되는지 확인합니다. 재생이 실패하면 진행 상태를 보존하고 다시 듣게 합니다. [MDN 자동 재생 안내](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)
3. 처음 보는 장면의 맥락을 이용해 정답을 유도합니다. 과제 화면에 정답을 미리 노출하지 않고, 실제 인출 뒤에만 해당 결과를 학습 기록으로 남깁니다.
4. 동일 카드로 아들과 딸을 번갈아 사용해 서로의 기록이 섞이지 않는지 확인합니다. 틀린 구간 추정은 직접 오답으로 되돌아와야 합니다. 장기 복습 제한과 하루 15분 종료도 확인합니다.
5. 첫 책의 사진이 들어오면 실제 본문에서 확인한 장면과 승인 팩을 우선 사용합니다. 신규 어휘와 시리즈 말장난의 출현 확인은 그때 가능합니다. 배포 전 실제 앱 및 iPad의 음성·진행·저장 검증이 필요합니다.
