# 공통 에셋·두 세계 연결 인계

기준: 아트·음악 1차 제작과 별도 두 세계 체험. 기존 `cards/js/*`, `cards/css/*`, `tests/*`, Mac 음성 파일·기존 state는 수정하지 않았다. 에셋 폴더는 `assets/post-office/v1`, 실제 사용 예제는 `showcase/post-office`다.

## Claude가 연결할 접점

1. `sprites.svg` symbol을 프로젝트의 SVG wrapper로 표시한다. manifest.symbols의 viewBox 크기와 animations의 프레임 ID를 읽는다. 캐릭터 walk1/walk2는 약 130ms 전환, 이동 완료는 idle, 성공은 happy다. reduced-motion에서는 프레임·위치 이동을 줄인다.
2. 두 세계의 지형·건물·카드 표시를 실제 v3 지도에 연결한다. 현재 showcase의 words-demo.json은 60단어 시제품 샘플이며 정식 worlds.json이 아니다. 샘플의 카드 배정을 그대로 4,610개 생성 결과로 사용하지 않는다.
3. 준비된 단어 음원 manifest의 `files[card_id] → filename`이 해당 카드 ID와 일치하는지 검사한다. 서버 --audio-dir로 기존 폴더를 직접 연결해 음원을 복제·재생성하지 않고 시험할 수 있다. 음성 재생 오류·첫 재생·빠른 다시 듣기·화면 잠금 후 복귀를 iPad에서 확인한다.
4. 음악·효과음과 단어 음성 채널을 분리한다. 단어가 재생되는 동안 BGM을 낮추고 FX를 겹치지 않게 한다. 음성 ended/취소/오류에서 복구한다. 음악과 FX의 켜기/끄기는 별도다. AAC 재생을 쓰고 MIDI는 편집 원본으로 보관한다.
5. 새 우체통 놀이를 옵션으로 연결한다. 현재 showcase의 타이밍 게임은 서서히 왕복하는 우체통이 노란 영역에 왔을 때 보내는 3회 체험이다. 놀이 결과는 장식 도장뿐이며 복습/단어 등급/학습 완료/별/박쥐를 변경하지 않는다. 도장은 profile+world+node 기준 한 번 지급하고 병합은 합집합이다.
6. 별도 체험 화면은 두 프로필의 메모리 상태만 사용한다. 실제 게임의 기존 저장·동기화에 연결하려면 기존 카드 상태의 마이그레이션·세계별 성/노드/도장을 함께 검증한다. 체험 상태나 6장 체험성 규칙을 실제 데이터에 복사하지 않는다.

## 아직 안 한 것

- 실제 4,610개 어휘·뜻/동음 분리·전체 음원 ID 매핑.
- 실제 iPad 음성/스피커 검수와 두 아이 사용.
- 정식 12장 성·박쥐·만기 복습을 포함한 전체 게임 라우팅과 두 기기 동기화.
- 친구 3종의 독립 표정 애니메이션과 나머지 지형 네 세트. 현재 친구는 정지 SVG 원형이다.

제작본은 `tools/build_postal_assets.py`로 재생성할 수 있다. 프로젝트용 원본 SVG·짧은 작곡이며 타 게임 에셋을 복사하지 않았다. Galmuri의 OFL 파일은 별도 보존한다. 단어 합성 음원을 검수 완료로 표기하지 않는다.
