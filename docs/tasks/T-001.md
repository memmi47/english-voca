# T-001 기능어 집을 학습 경로에서 제외하라

- 상태: 완료
- 담당 층: 실행 (Sonnet)
- 선행 카드: 없음 (C-001과 독립. 어느 쪽이 먼저 병합돼도 동작해야 한다)
- 브랜치: `claude/t-001-no-sight-houses` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

아이의 지도에서 "빨리 읽기 집"이 사라지고, 기능어 121장을 만나지 않아도 왕관과 대륙 성이 열린다.

## 배경

- 사용자 결정 2026-11-16 (`docs/LEARNING_VALUE_SPEC.md` 2.1절): 기능어는 낱개 카드로 읽기에 도움이 적고, "소리 듣고 글자 고르기"는 너무 쉬운 문제다.
- 세계 파일(`cards/data/worlds.json`)에는 지금 세계마다 `sideActivities` 안에 `kind: "sight"` 집이 있다. C-001이 끝나면 파일에서도 빠지지만, 게임은 파일에 집이 남아 있어도 무시해야 한다.
- 이미 기능어 카드를 만난 아이의 기록(`state.words`)은 그대로 둔다. 지우지 않는다.

## 고칠 수 있는 파일

- `cards/js/world.js`, `cards/js/main.js`(집을 그리는 부분), `tests/cards.test.mjs`, `tests/cards_e2e.cjs`, `tools/make_cards_demo.py`와 그 결과(`cards/data/demo/*`)는 **고치지 않는다**(체험판에 집이 남아 있어야 "무시한다"를 시험할 수 있다)
- `docs/tasks/T-001.md`의 결과 절, `docs/tasks/BOARD.md`의 상태

## 할 일

1. `cards/js/world.js`에 설정 하나를 둔다: 학습 경로에서 빼는 집의 종류. 기본값은 `sight`. 이 종류의 집은 `unitsOf`(왕관·세계 단어 수의 근거), `worldView`의 `houses`, `nodeRun`에서 모두 빠진다. `phrase` 집은 그대로 동작한다.
2. 성 시험과 대륙 성의 출제 풀(`worldWords`)에서도 빠진다.
3. "소리 듣고 글자 고르기" 카드 코드(`deck.js`의 `isSight` 분기, `main.js`의 듣기 화면)는 지우지 않는다. 설정을 비우면 예전처럼 집이 나타나야 한다.
4. 부모 화면의 "만난 카드 a/b"에서 b는 학습 대상 수(집을 뺀 수)로 보여 준다.

## 바꾸면 안 되는 것

- 저장 형식(`SCHEMA`), 카드 id, 세계 id. 이 카드는 저장 형식을 바꾸지 않는다.
- `cards/js/deck.js`의 복습 규칙, `cards/js/map.js`.
- `tests/cards_safety.test.mjs`와 `tests/fixtures/saves/*`.

## 완료 기준

```sh
node --test tests/*.test.mjs     # 전부 통과
node tests/cards_e2e.cjs         # 전부 통과
```

새로 있어야 하는 검사:
- 단위: 기본 설정에서 체험판 세계 `d1-01`의 `worldView(...).houses`가 비어 있고, 기능어를 하나도 만나지 않아도 모든 칸 + 성 통과로 `crown`이 true다. 성 시험 풀에 기능어가 없다. 설정을 비우면(집 종류 제외 없음) 기존 W8·W9 검사가 그대로 통과한다(기존 검사는 이 설정을 비운 상태로 돌리도록 고친다. 지우지 않는다).
- 브라우저: 체험판 지도에 `[data-id=H1]`이 없다. 기존 10c의 집 관련 검사는 설정을 켜는 시험용 주소 옵션(`?houses=sight`)으로 돌리거나 단위 검사로 옮긴다. 검사 수가 줄면 결과에 무엇을 옮겼는지 적는다.
- 브라우저: 기능어 6장을 이미 만난 기록(`tests/fixtures/saves/v1-worlds.json`)을 넣고 열어도 그 단어 기록이 남아 있다.

## 결과

- `world.js`: 설정 `setLeftOutKinds`(기본 `sight`, 비우면 예전 동작)를 두고 `unitsIn`(설정별 캐시)으로 `unitsOf`·`worldWords`·`crowned`·`worldView.houses`·`nodeRun`·`settleWorld`에서 그 종류의 집을 뺐다. `phrase` 집, `deck.js`의 `isSight`, 듣기 화면은 그대로다.
- `main.js`: 시험용 주소 옵션 `?houses=sight`(설정을 비움), 부모 화면 "만난 카드 a/b"의 b를 학습 경로의 카드 수로 바꿨다.
- 단위: W1·W2·W6·W8·W9·M9·G2는 집이 필요해 설정을 비운 채 돌리고 끝나면 기본값으로 되돌린다(`legacyTest`). 새 W12: 기본 설정에서 집·기능어 없음, 기능어 없이 모든 칸 + 성으로 왕관, 성 풀에 기능어 없음, 설정을 비우면 집 복귀. 결과: 58/58 통과.
- 브라우저: 10c는 `?houses=sight`로 돌린다. 새 검사 3개(기본 지도에 H1 없음, 기능어 6장이 든 v1-worlds 기록이 열기·한 칸 뒤에도 남음 2개). 바뀐 기존 검사 2개: 섹션 1의 이름표 수 5 이상을 4 이상으로, 섹션 6의 "보너스 x2" 표시 수를 3에서 2로(집이 빠져서). 결과: 118/118 통과. 검사를 지우거나 옮기지 않았다.
- 확인하지 못한 것: 기기(iPad) 확인 목록, 전체 카드 세트(4,610장)에서의 "만난 카드 a/b" 표시.
- 검토(설계 층, 2026-11-16): 보고서에는 기본 설정용 새 단위 검사가 있다고 적혀 있었으나 파일에 없었다. W13으로 추가했다. 병합 뒤 단위 59/59, 브라우저 118/118.
