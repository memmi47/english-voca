# C-023 꾸미기: 우스꽝스럽고 눈에 확 띄는 모자·가방·옷

- 상태: 대기
- 담당 층: 설계 (Astra: 아이템 목록과 시안) → 사용자 확인 → 구현 (Sol)
- 선행 카드: C-019, C-021(모양 차별화)
- 브랜치: `codex/funny-gear` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

지금 모자·가방·옷은 기본 차림과 차이가 작아 모으고 싶은 마음이 덜하다(사용자 2026-11-20). 픽셀 게임에서 흔한, 말도 안 되지만 웃긴 아이템으로 채워 상상력을 키운다. 사용자 예: "머리에 생선이 달린 모자"(예시일 뿐).

## 방향

- 실루엣이 기본 차림과 확 다르다: 머리 위로 크게 솟거나, 몸보다 큰 가방, 몸 전체를 바꾸는 옷.
- 배달부 이야기와 엮는다(우편·편지·동물·음식·날씨 등). 다른 게임의 아이템을 흉내 내지 않는다.
- 뒤 대륙일수록 더 크고 화려하게(대륙 1 < 2 < 3). 반짝임은 지금처럼 대륙 3에서만.
- 아이 둘 모두에게 어울려야 한다. 딸의 하트·아들의 목도리·머리 모양이 가려지지 않는다.

## 후보 예시 (Astra가 고르고 더한다)

| 칸 | 예 |
|---|---|
| 모자 | 생선이 꼬리 치는 모자, 우체통 모자(입구로 편지가 들락날락), 회오리 모자, 케이크 모자(촛불), 프로펠러 모자, 박쥐 날개 모자, 화분 모자(꽃이 핌) |
| 가방 | 상어 입 가방, 풍선 다발 가방, 거대 우표 가방, 로켓 배낭, 거북 등딱지 가방 |
| 옷 | 공룡 옷, 바나나 옷, 편지 봉투 옷, 기사 갑옷, 우주복, 구름 옷 |

## 정할 것

1. 칸별 아이템 목록, 각 아이템이 처음 나오는 곳(기존 C-019 배치: 세계 성 3/7/4개, 대륙별 등급)과 바꿀 기존 아이템.
2. 움직임: 지도에서 2~3프레임 정도의 작은 움직임(생선 꼬리, 프로펠러)을 둘지. iPad 부담을 넘지 않게.

## 확인 단계 (구현 전)

Astra가 시안 한 장을 만든다: 칸별로 모든 새 아이템을 아들·딸에게 입힌 그림(카드 크기와 지도 크기 80px). 경로를 결과에 올리고 **"사용자 확인 대기"로 멈춘다.** 개발자 놀이터(부모 기록 → 개발자 놀이터 → 세계 바로 가기 → 지도의 꾸미기)에서는 모든 아이템을 바로 입어 볼 수 있다.

## 고칠 수 있는 파일

- 꾸미기 그림 생성기와 그 출력, 아이템 목록(`cards/js/main.js`의 꾸미기 부분), 그림 검사 도구, `tests/cards_e2e.cjs`(바뀐 그림의 기대값), 이 카드의 결과, `docs/tasks/BOARD.md`, `docs/WORKLOG.md` 8절 한 줄.

## 바꾸면 안 되는 것

- 이미 연 아이템을 다시 잠그지 않는다. 아이가 고른 차림(`cards.v0.look.*`)은 없어진 아이템이면 기본으로 돌아가되 기록은 지우지 않는다.
- 보상은 학습 일정과 등급을 바꾸지 않는다. 이모지를 그림으로 쓰지 않는다. 기존 검사를 약하게 하지 않는다.
