# T-008 지도에 배달부와 회오리를 세우고 회오리 판 화면을 만들어라

- 상태: 대기
- 담당 층: 구현 (Opus)
- 선행 카드: T-007(병합 뒤 시작), C-004(완료)
- 브랜치: `t-008-storm-screen` (기준 `claude/modest-mccarthy-3gadjk`. 푸시하지 않는다. 설계 층이 검토 후 병합한다)

## 목표

아이가 지도에서 자기 위치(배달부)와 다가오는 회오리를 보고, 회오리에 닿으면 변신 단어 5장을 풀어 빠져나온다.

## 배경

- 규칙은 `cards/js/storm.js`(T-007)에 있다. 이 카드는 그 규칙을 화면에 붙이기만 한다. 규칙을 바꿔야 하면 멈추고 적는다.
- 도안(C-004): `fx-storm-a`, `fx-storm-b`(두 프레임), `fx-storm-letters`, `fx-storm-gone`. 배달부 도안은 이미 있다(`courier-<색>-idle` 등, `cards/assets/postal/manifest.json`). 그리는 함수는 `cards/js/main.js`의 `spr`, `anim`.
- `docs/LEARNING_VALUE_SPEC.md` 2.6절. 회오리는 실시간으로 움직이지 않는다. 판이 끝난 뒤 지도로 돌아올 때 한 칸 움직인다.

## 만들 것

1. 시작할 때 `cards/data/forms.json`을 읽는다. 없거나 읽지 못하면 회오리 없이 지금처럼 동작한다(오류 화면을 띄우지 않는다). demo 세트(`?set=demo`)는 같은 `forms.json`을 쓰되, 원형이 demo 카드 목록에 있는 형태만 남긴다.
2. 지도: 배달부를 `here` 칸 위에 세운다. 회오리가 있으면 그 칸 위에 두 프레임으로 돌린다. 칸 번호·자물쇠·별 표시를 가리지 않게 칸의 위쪽에 겹친다.
3. 판이 끝나 끝 화면을 닫을 때 `stormTick`을 부르고 결과에 따라:
   - `spawn`: 지도에 회오리가 나타나고 한 줄 알림("회오리가 나타났어요").
   - `move`: 지도에서 한 칸 옮겨 그린다(이전 칸에서 새 칸으로 0.4초 미끄러짐, `?fast=1`이면 즉시).
   - `caught`: "회오리에 휩쓸렸어요!" 화면을 잠깐 보여 주고 회오리 판을 시작한다.
   - `gone`: 사라지는 도안을 한 번 보여 준다.
4. 잡힌 동안 그 세계의 칸·몬스터·복습 버튼을 누르면 회오리 판으로 간다. 회오리를 직접 눌러도 회오리 판이 시작된다. 박쥐가 가득 차 있으면 지금처럼 박쥐가 먼저다.
5. 회오리 판 화면: 가운데에 변신한 형태를 크게, 아래에 원형 보기 세 개(글자 버튼). 고르면 맞음/틀림과 함께 "ran → run 달리다"처럼 원형과 그 카드의 한글 뜻을 보여 준다. 시제나 복수의 한글 설명은 만들지 않는다. "다음"으로 넘어간다. 왼쪽 위 나가기는 다른 판과 같다(나가면 회오리가 남는다).
6. 소리: 형태의 음원 파일이 있으면 카드가 뜰 때 한 번 재생하고, 없으면 조용히 넘어간다(오류 없음). 음원 목록은 `cards/audio/forms.tsv`(형태 id, 글자)로 따로 만든다. 생성기는 `tools/make_cards_data.py`에 덧붙이고, 음원 스크립트 `tools/cards_say_audio.sh`가 이 목록도 읽게 한다(파일 이름 규칙은 단어 음원과 같은 방식). 효과음은 기존 것(`sfxPlay`)을 쓴다.
7. 끝 화면: 맞힌 수와 받은 별. "회오리에서 빠져나왔어요". 복습 일정에 관한 문구는 없다.
8. 부모 화면: 변신 단어 진행 한 줄(끝난 형태 수 / 낼 수 있는 형태 수).
9. 시험용 주소 옵션: `?storm=off`(회오리 끔), `?storm=now`(조건이 되면 확률 없이 바로 생김). `?storm=now`는 시험에서만 쓴다.

## 고칠 수 있는 파일

- `cards/js/main.js`, `cards/css/app.css`
- `tools/make_cards_data.py`(forms.tsv 생성만), `tools/cards_say_audio.sh`(목록 하나 더 읽기), 새 파일 `cards/audio/forms.tsv`
- `tests/cards_e2e.cjs`
- `README.md`(음원 절에 한 줄), `docs/tasks/T-008.md`의 결과, `docs/tasks/BOARD.md`의 상태

## 바꾸면 안 되는 것

- `cards/js/storm.js`·`deck.js`·`map.js`·`world.js`·`store.js`·`sync.js`의 규칙(버그를 찾으면 고치지 말고 결과에 적는다. 한 줄짜리 내보내기 추가는 된다).
- `cards/data/*`, `cards/assets/*`, `reference/`, `.github/`.
- 합성 음원을 "사람이 검토함"으로 표시하지 않는다.
- 형제 기록을 비교하는 화면을 만들지 않는다.
- 기존 브라우저 검사를 지우거나 약하게 하지 않는다. 회오리 때문에 기존 검사의 흐름이 흔들리면 그 검사에 `?storm=off`를 붙이는 대신, 검사 묶음 전체의 기본 주소에 `storm=off`를 넣고 새 회오리 검사에서만 켠다. 그렇게 한 사실을 결과에 적는다.

## 완료 기준

```sh
node --test tests/*.test.mjs
node tests/cards_e2e.cjs            # 필요하면 NODE_PATH=$(npm root -g)
python3 -I tools/make_cards_data.py # forms.tsv가 127줄(낼 수 있는 형태)로 생긴다. 다른 산출물은 바뀌지 않는다
bash -n tools/cards_say_audio.sh
```

새 브라우저 검사(13절 "회오리", demo 세트 + `?storm=now` + 고정 씨앗):

1. 변신 형태가 있는 단어를 5개 이상 만난 기록으로 판을 끝내면 지도에 회오리와 배달부가 보인다.
2. 판을 더 끝내면 회오리의 칸이 배달부 쪽으로 바뀌고, 닿으면 회오리 판이 시작된다.
3. 잡힌 상태에서 새로 고쳐도 잡힌 채이고, 칸을 누르면 회오리 판으로 간다.
4. 회오리 판에서 하나를 틀리면 그 카드가 끝에 한 번 더 나온다. 판 전후로 단어 기록(`words`)이 같다.
5. 끝내면 회오리가 없어지고 칸을 다시 누를 수 있다. 별이 늘었다.
6. `forms.json`을 못 읽는 경우(요청을 막아 시험) 게임이 그대로 열리고 회오리가 없다.
7. 박쥐가 가득 찬 기록에서는 회오리가 움직이지 않고 박쥐 시험이 먼저 열린다.
