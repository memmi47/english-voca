## 배경

2026-11-18 Claude가 병합 직후 iPad 크기로 찍은 화면에서 확인한 것 [verified: 화면 캡처].

| # | 화면 | 지금 | 바꿀 것 |
|---|---|---|---|
| 1 | 꾸미기 "옷" 칸 | 예전 별 선물 여섯 벌(잎사귀 모자, 햇살 가방, 물결 옷, 밤하늘 모자, 편지 가방, 축제 옷)이 모두 "옷" 칸에 있다. 이름이 모자·가방인데 옷 칸에 있어 헷갈린다 | 각자 이름에 맞는 칸(모자·가방·옷)으로 옮긴다. 이미 받은 아이에게는 그대로 열린 상태. 여는 조건(별 12/40/100/240/500/1000)은 이 여섯 개에만 남기고 "별 선물" 표시를 붙인다. 새 아이템의 여는 조건(성·대륙 성·익힌 단어)은 그대로 |
| 2 | 꾸미기의 잠긴 아이템 | 그림 자리에 회색 막대만 있다. 무엇을 얻을지 보이지 않는다 | 아이템 모양 그대로의 어두운 실루엣(채운 진한 색, 윤곽 보임)을 보여 준다. 여는 조건 한 줄은 그대로 |
| 3 | 세계 지도(대륙 그림 지도) | 마을마다 "이 세계의 선물: ○○" 글 상자가 붙어 지도가 복잡하고 글자가 작다 | 마을 옆에는 선물 아이콘(작은 그림)만. 마을을 누르면 나오는 안내에 이름을 보여 준다. 받은 선물은 아이콘에 확인 표시 |
| 4 | 각 세계 지도 위쪽 "이 세계의 선물" | 아이콘이 매우 작다 | 아이콘을 글자 높이의 두 배로 |

## 고칠 수 있는 파일

- `cards/js/main.js`, `cards/css/app.css`, 그림 생성기와 그 출력(실루엣이 그림에서 필요할 때만)
- `tests/cards_e2e.cjs`(검사 추가. 아이템 칸 이동으로 기존 검사의 선택자가 바뀌면 같은 것을 확인하도록 바꾸고 결과에 적는다)
- `docs/tasks/C-018.md`의 결과, `docs/tasks/BOARD.md`, `docs/WORKLOG.md` 8절 한 줄

## 바꾸면 안 되는 것

- 규칙 코드, 저장 형식, 아이 기록의 저장 키, 아이템 id. 기기별 꾸미기 저장(`cards.v0.look.<아이>`)에서 예전 별 선물을 옷 칸에 입고 있던 기록은 새 칸으로 옮겨 그대로 입은 상태가 되게 한다.
- 이미 열린 아이템을 다시 잠그지 않는다. 보상이 학습에 영향을 주지 않는다.
- 기존 검사를 지우거나 약하게 하지 않는다. `node tools/check_sim_baseline.mjs`의 `--update`는 쓰지 않는다.

## 완료 기준

```sh
node --test tests/*.test.mjs
node tests/cards_e2e.cjs
node tools/check_sim_baseline.mjs      # 그대로
```

새 브라우저 검사(최소):

1. 꾸미기 각 칸에 그 칸 종류의 아이템만 있다(이름의 모자·가방·옷과 칸이 맞음).
2. 예전 별 선물(예: 잎사귀 모자)을 입고 있던 기기 기록을 넣고 열면 모자 칸에서 입은 상태로 보인다.
3. 잠긴 아이템마다 실루엣 그림이 있다(빈 막대가 아님).
4. 세계 지도의 마을 옆에 글 상자가 없고, 마을을 누르면 선물 이름이 보인다.

화면 캡처(저장소 밖): 꾸미기 모자 칸, 잠긴 아이템, 세계 지도. 경로를 결과에 적는다.
