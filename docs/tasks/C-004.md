# C-004 회오리 도안을 그려라

- 상태: 대기
- 담당 층: 실행 (Terra)
- 선행 카드: 없음
- 브랜치: `codex/storm-sprites` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

지도 위를 돌아다니다 아이에게 다가오는 "회오리"를 그릴 도안이 생긴다.

## 배경

- `docs/LEARNING_VALUE_SPEC.md` 2.6절. 회오리는 판이 끝날 때마다 한 칸씩 배달부 쪽으로 다가오고, 만나면 변신 단어 카드 5장을 푼다. 무섭지 않고 장난스러운 느낌이어야 한다(저학년, 폭력·공포 표현 금지).
- 도안 규칙은 기존 세계 픽셀 도안과 같다: 16×16 정수 격자, 프로젝트 팔레트(청록 외곽선 `#233F3A`, 크림, 차분한 금색·산호색), 외부 게임 그림을 베끼지 않는다. `docs/WORLD_PIXEL_HANDOFF.md` 참고.
- 배달부(아이의 위치)는 기존 `cards/assets/postal/sprites.svg`의 `courier-teal-*`, `courier-gold-*`를 쓴다. 새로 그리지 않는다.

## 만들 것

`cards/assets/postal/world-pixels/sprites.svg`에 기호 4개를 추가한다(기존 기호와 id가 겹치지 않게).

| id | 내용 |
|---|---|
| `fx-storm-a`, `fx-storm-b` | 회오리 2프레임. 번갈아 보여 주면 도는 것처럼 보이게 |
| `fx-storm-letters` | 회오리 안에서 글자 조각이 날리는 모습(회오리 판 화면의 머리 그림용) |
| `fx-storm-gone` | 사라질 때의 작은 바람 자국 1프레임 |

- 모든 기호의 `viewBox`는 `0 0 16 16`. `manifest.json`에 이름과 역할을 적는다.
- 밝은 땅(연두)과 어두운 땅(밤하늘 세계) 위에서 모두 보이게 외곽선을 둔다.

## 고칠 수 있는 파일

- `tools/postal_pixel_recipes.py`, `tools/build_world_pixel_assets.py`, `tools/check_world_pixel_assets.cjs`
- 생성 결과: `cards/assets/postal/world-pixels/sprites.svg`·`manifest.json`, `assets/post-office/world-pixels/pixels.json`, `cards/art-review/*`

## 바꾸면 안 되는 것

- 기존 180개 보스 도안과 장식 별칭의 id와 픽셀. `cards/data/worlds.json`(이 카드에서는 다시 생성하지 않는다).
- `cards/js/*`, `cards/css/*`, `tests/*`.

## 완료 기준

```sh
python3 -I tools/build_world_pixel_assets.py --check    # 통과, 보스 180개는 그대로
node tools/check_world_pixel_assets.cjs                 # 통과, 새 기호 4개 포함
node tests/cards_e2e.cjs                                # 전부 통과
```

`cards/art-review/`에서 새 도안 4개를 밝은 땅·어두운 땅 위에 나란히 볼 수 있다.
