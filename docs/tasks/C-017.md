# C-017 아들·딸 배달부의 기본 모습을 다르게: 머리 모양, 표시, 제자리 움직임

- 상태: 대기
- 담당 층: 구현 (Sol). 그림은 Astra가 최종 확인
- 선행 카드: C-016(배달부 그림을 층으로 나눈 뒤. 그 브랜치 위에 쌓거나 병합 뒤)
- 브랜치: `codex/kid-looks` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

지도처럼 작은 화면에서도 아들과 딸의 배달부가 한눈에 구별되고, 둘 다 "내 캐릭터"라고 느낀다.

## 배경 (사용자 결정 2026-11-18)

- 지금은 색만 다르다(아들 청록, 딸 금색). 지도 크기에서 거의 구별되지 않는다.
- 사용자가 시안을 보고 정했다: 머리 모양(A) + 고정 표시(B) + 제자리 움직임 성격(C). 딸의 표시는 리본이 잘 안 보여 모자 앞 하트로 바꾼다. 움직임은 아들이 좌우로, 딸이 통통 뛰기(아들은 움직임이 작은 편, 딸은 액션이 큰 편). **움직임의 범위는 두 아이가 비슷해야 한다(한 아이가 서운해하지 않도록). 다른 것은 속도와 방향뿐.**
- 시안: Claude가 2026-11-18 만든 확인용 시안(기존 48×48 배달부 위에 픽셀을 덧그린 것). 아래 표가 그 내용이다. 픽셀은 다듬어도 되지만 윤곽·위치·색·움직임 크기는 지킨다.

## 정한 모습

| | 머리 모양 | 표시(처음부터 가진 것) | 제자리 움직임 | 색 |
|---|---|---|---|---|
| 아들 | 모자 밑으로 삐친 짧은 머리(앞머리 몇 가닥 + 뒤로 한 가닥) | 빨간 목도리, 끝이 오른쪽 뒤로 날림 | 좌우로 흔들기: 왼쪽 2px → 가운데 1px 내려앉기 → 오른쪽 2px → 가운데 1px 내려앉기. 한 바퀴 약 1.4초 | 청록 |
| 딸 | 양 갈래 머리(어깨까지, 분홍 머리끈) | 모자 앞 가운데 분홍 하트(지금 모자의 흰 띠 자리, 약 9×8px, 진한 분홍 + 밝은 반짝임 + 진한 테두리) | 통통 뛰기: 0 → 위 2px → 위 3px → 위 2px. 한 바퀴 약 0.8초 | 금색 |

- 픽셀 단위는 48×48 그림 기준이다. 지도 크기(C-016, 약 72~88px)에서는 비례해 커진다.
- 움직임 크기는 두 아이 모두 2~3px 안이다. 한쪽만 크게 하지 않는다.
- 숨쉬기·눈 깜박 프레임(C-014·C-016)과 합친다. "움직임 줄이기"를 켜면 둘 다 똑같이 멈춘다.
- 걷기, 기쁨, 손 흔들기 등 다른 동작 프레임에도 머리 모양과 표시가 똑같이 들어간다.
- 모자 아이템을 바꿔도 딸의 하트는 새 모자 앞 가운데에 남는다(모자 층 위에 표시 층). 아들의 목도리는 옷 아이템 위에 남는다. 머리 모양은 모자 아래로 보인다.
- 첫 화면, 지도, 카드 판의 던지기 동작, 꾸미기 화면, 성 연출 등 배달부가 나오는 모든 곳에 적용한다.

## 바꾸면 안 되는 것

- 규칙 코드, 저장 형식, 저장 키, 아이 기록. 이 카드는 그림과 움직임만 바꾼다.
- 기존 검사를 지우거나 약하게 하지 않는다. `node tools/check_sim_baseline.mjs`의 `--update`는 쓰지 않는다.
- 다른 게임의 캐릭터를 흉내 내지 않는다.

새 브라우저 검사(최소):

1. 아들 지도와 딸 지도의 배달부 그림이 서로 다르다(머리·표시 요소가 각자에게만 있음).
2. 두 아이의 제자리 움직임 최대 이동 거리가 둘 다 3px 이하이고 차이가 1px 이하다.
3. 딸이 다른 모자를 고르면 하트가 그 모자 앞에 그대로 보인다. 아들이 다른 옷을 고르면 목도리가 보인다.
4. "움직임 줄이기"를 켜면 두 아이 모두 멈춘다.

화면 캡처(저장소 밖): 카드 크기 두 아이, 지도 위 두 아이(나란히), 모자를 바꾼 딸, 옷을 바꾼 아들. 경로를 결과에 적는다.
