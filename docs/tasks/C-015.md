새 브라우저 검사(최소):

1. 세계 지도에서 대륙마다 그림 지도 하나가 보이고, 열린 세계를 누르면 그 세계로 간다. 잠긴 세계는 가지 않는다.
2. 성 조건 상자가 어떤 칸·성·우표 표시와도 겹치지 않는다(요소 사각형 비교).
3. 꾸미기의 모든 옷차림 그림이 기본 배달부와 같은 크기(그림 상자 너비·높이)다.
4. 가장 긴 뜻을 가진 카드 몇 장에서 보기 버튼 세 개의 높이가 같고, 버튼 밖으로 글자가 넘치지 않는다.
5. 별 1000개 기록에서 지도 위쪽 줄이 한 줄이다.
