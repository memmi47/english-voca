# C-012 Mac 집 안 서버 설치 스크립트: 자동 시작, 게임 폴더 밖 기록 폴더, 매일 백업

- 상태: 대기
- 담당 층: 구현 (Sol)
- 선행 카드: 없음
- 브랜치: `codex/mac-setup` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

부모가 Mac에서 명령 한 줄로 게임 서버를 상시 운영 상태로 만든다. Mac을 켜면 서버가 자동으로 뜨고, 아이들 기록은 게임 폴더 밖에 있어 업데이트가 건드리지 않으며, 매일 비공개 저장소로 백업된다. 되돌리는 명령도 한 줄이다.

## 배경 (사용자 결정 2026-11-17)

- 구동 방식: Mac을 집 안 서버로 쓰고 아이들은 iPad Safari(홈 화면에 추가)로 접속한다. Mac은 유선(이더넷), iPad는 무선(Wi-Fi)으로 같은 공유기에 연결된다.
- 기록 보호 규칙은 `docs/DATA_SAFETY.md`. 서버는 `tools/serve_cards.py`(`--host`, `--port`, `--state-dir`, 환경 변수 `CARDS_STATE_DIR`), 백업은 `tools/backup_state.sh`(`CARDS_BACKUP_REPO`, 비공개 저장소만 허용).
- 지금까지 부모가 기본값으로 서버를 실행했다면 기록이 게임 폴더 안의 `state-cards/`에 있다. 이 기록을 잃으면 안 된다.

## 만들 것

1. `tools/install_mac.sh`
   - 하는 일을 먼저 모두 화면에 보여 주고 `y`를 입력해야 진행한다. `--dry-run`이면 보여 주기만 한다.
   - 기록 폴더: 기본 `~/english-voca-data`(인자 `--data DIR`로 변경). 없으면 만든다. 게임 폴더 안의 `state-cards/`에 기록이 있고 새 폴더가 비어 있으면 **복사**한다(옮기거나 지우지 않는다). 새 폴더에 이미 기록이 있으면 아무것도 덮어쓰지 않고, 두 폴더의 파일 목록과 수정 시각을 보여 준 뒤 멈춘다.
   - 서버 자동 시작: 사용자 LaunchAgent(`~/Library/LaunchAgents/com.english-voca.server.plist`)로 `python3 tools/serve_cards.py --host 0.0.0.0 --port 8090 --state-dir <기록 폴더>`를 로그인 때 시작하고 꺼지면 다시 띄운다. 로그는 `~/Library/Logs/english-voca-server.log`.
   - 매일 백업(선택, `--backup-repo DIR`를 줄 때만): LaunchAgent `com.english-voca.backup`이 매일 21:07에 `CARDS_STATE_DIR=<기록 폴더> CARDS_BACKUP_REPO=<DIR> bash tools/backup_state.sh`를 실행한다. 비공개 저장소 확인은 스크립트가 이미 한다.
   - 관리자 권한(`sudo`)을 쓰지 않는다. 시스템 설정(잠자기, 방화벽)을 바꾸지 않는다. 필요하면 문서에 부모가 할 일로 적는다.
   - 끝나면 접속 주소를 보여 준다: `http://<컴퓨터 이름>.local:8090`(`scutil --get LocalHostName`)과 IP 주소(유선·무선 인터페이스 모두에서 찾은 것), 그리고 `/api/ping` 응답 확인 결과.
2. `tools/uninstall_mac.sh`: 두 LaunchAgent를 내리고 plist를 지운다. 기록 폴더와 백업은 절대 지우지 않는다.
3. `tools/update_mac.sh`: 게임 업데이트. `git pull` 전에 기록 폴더의 오늘 사본을 `<기록 폴더>/before-update/<시각>/`에 복사하고, pull 뒤 서버를 다시 시작하고 `/api/ping`을 확인한다. 업데이트가 실패하면 서버를 이전 상태로 둔다(코드를 되돌리지는 않고 알린다).
4. `docs/SETUP_MAC.md`: 부모용 한글 안내. 설치·업데이트·제거 명령, iPad에서 여는 주소와 홈 화면 추가, 확인 방법, 그리고 "안 열릴 때" 표(같은 공유기인지, 게스트 Wi-Fi·기기 간 차단, Mac 잠자기, 방화벽 허용, `.local` 이름이 안 될 때 IP로, 공유기에서 Mac에 고정 IP 주기). 기록이 어디에 몇 겹으로 남는지 한 단락.

## 바꾸면 안 되는 것

- `tools/serve_cards.py`, `tools/backup_state.sh`, `cards/*`, `tests/fixtures/*`, `reference/`.
- 어떤 경우에도 기록 폴더·`state-cards/`·백업 저장소의 파일을 지우거나 덮어쓰지 않는다.
- 이 작업 환경(리눅스)에서 실제 LaunchAgent를 등록하지 않는다.

## 완료 기준

```sh
bash -n tools/install_mac.sh tools/uninstall_mac.sh tools/update_mac.sh
shellcheck tools/*_mac.sh            # 설치돼 있으면. 없으면 결과에 적는다
node --test tests/*.test.mjs         # 전부 통과 (지금 100 + 새 검사)
```

새 검사(`tests/mac_setup.test.mjs`, 임시 HOME과 가짜 `launchctl`·`scutil`로 실제 스크립트를 실행):

1. `--dry-run`은 아무 파일도 만들지 않는다.
2. 게임 폴더의 `state-cards/`에 기록이 있고 새 폴더가 비어 있으면 복사되고, 원본은 그대로 남는다(내용 해시 비교).
3. 새 폴더에 이미 기록이 있으면 아무 파일도 바뀌지 않고 0이 아닌 코드로 멈춘다.
4. 만든 plist에 기록 폴더 경로와 `--host 0.0.0.0`이 들어 있고 `plutil -lint`가 있으면 통과한다(없으면 XML 파서로 확인).
5. `uninstall_mac.sh` 뒤 plist는 없고 기록 폴더 파일은 그대로다.
6. `update_mac.sh`는 pull 전에 `before-update/` 사본을 만든다(가짜 git 저장소로).
