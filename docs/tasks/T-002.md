# T-002 시뮬레이터에 배치 진단·훑기·표본 확인을 넣고 수치를 보고하라

- 상태: 검토 (사용자 결정 대기: 배치 진단을 뺄지)
- 담당 층: 설계 (Fable)
- 선행 카드: 없음
- 브랜치: `claude/t-002-sim-triage` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

`docs/LEARNING_VALUE_SPEC.md` 2.2~2.4의 제안이 아이의 시간을 얼마나 줄이고 기억에 구멍을 얼마나 남기는지 숫자로 알게 되어, 사용자가 항목별로 승인할 수 있다.

## 배경

- 기준값(지금 규칙, 기준 아이, 몬스터 50%): 전체 완료 54주, 52주에 모르던 단어의 79% 기억 [estimate] (`docs/research/learning_load_sim.md`).
- 시뮬레이터 `tools/sim_learning.mjs`는 게임의 규칙 코드(`deck.js`, `map.js`)를 그대로 부른다. 이 카드에서는 게임 코드를 고치지 않고, 시뮬레이터 안에서 세 제안을 흉내 내는 선택지를 만든다(게임 구현은 T-003~T-005).
- 기능어 121장은 대상에서 뺀다(4,489장).

## 할 일

1. 선택지 세 개를 시뮬레이터에 넣는다.
   - 배치 진단: 쉬운 구간부터 6장씩 확인, 6장 중 5장 이상이면 그 구간을 "아는 듯"으로 넘기고 올라감, 3장 이하면 멈춤. 구간 수와 경계는 변수로.
   - 훑기: 칸에 들어가면 아는 단어는 카드 없이 "아는 듯"이 됨(단어당 2초로 계산). 모르는데 넘기는 비율은 아이 가정의 거짓 "알아요" 비율을 쓴다. 넘긴 단어 중 1~2개를 즉석 확인.
   - 표본 확인: 칸 단위 묶음에서 30일 뒤 3장만 확인. 모두 맞히면 묶음을 금으로, 아니면 묶음 전체를 7일 확인으로.
2. 기준 아이·약한 아이·강한 아이에 대해 지금 규칙과 비교한다. 지표: 전체 완료 주차, 52주의 기억 수, 하루 카드 수, 박쥐 카드 비중, 그리고 새 지표 "사실은 모르는데 금이 된 단어 수".
3. 표본 크기(3 / 5장)와 진단 통과 기준(6장 중 5 / 6)을 바꿔 가며 민감도를 본다.
4. `docs/research/learning_load_sim.md`에 절을 추가해 결과와 추천값을 적는다. 추천이 명세와 다르면 명세의 해당 줄에 표시한다.

## 고칠 수 있는 파일

- `tools/sim_learning.mjs`, `tools/sim_scenarios.mjs`, `docs/research/learning_load_sim.md`, `docs/research/learning_load_sim_tables.md`, `docs/LEARNING_VALUE_SPEC.md`(추천값 반영), `docs/tasks/*`

## 바꾸면 안 되는 것

- `cards/js/*`, `tests/*`. 기존 시나리오 묶음(`old`, `rules`, `chosen` 등)의 결과가 달라지면 안 된다(선택지를 끈 상태가 기본).

## 완료 기준

```sh
node tools/sim_learning.mjs --set chosen --seeds 3     # 기존과 같은 수치 (전체 완료 54주 안팎, 79% 안팎)
node tools/sim_learning.mjs --set triage --seeds 5     # 새 묶음: 세 선택지와 조합
node --test tests/*.test.mjs                            # 전부 통과
```

보고서에: 조합별 표, 추천값, 가정에 가장 민감한 지점, 반증 조건. 사용자에게 승인받을 항목을 세 줄 이내로.

## 결과

- 시뮬레이터에 선택지 다섯 개를 넣었다: `real`(실제 세계 4,489장), `gradient`(대역 안에서 아는 비율이 떨어짐), `triage`, `sample`, `placement`(취소 선택지 포함). 기본은 모두 꺼짐. `--set chosen --seeds 5`의 결과가 이전과 같음을 확인했다(기준·몬스터 50%: 54주, 2,276 / 2,891).
- 새 묶음 `triage`, `honest`를 5회 반복으로 돌렸다. 결과와 추천은 `docs/research/learning_load_sim.md` 8절, 원자료는 `docs/research/learning_value_sim_tables.md`.
- 추천: 훑기와 표본 확인(묶음당 5장)은 넣는다. 배치 진단은 넣지 않는다(이득 없음, 약한 쪽 손해). 배치 진단은 사용자가 승인했던 항목이라 재결정이 필요하다.
- 사용자에게 승인받을 것: ① 훑기 + 표본 5장으로 진행 ② 배치 진단을 빼는 것 ③ 금이 된 단어의 장기 확인(90일·180일)을 다음 검토 항목에 올릴지.
- 확인하지 못한 것: 가정(특히 대역 안의 아는 비율 기울기와 훑기에서의 정직성)은 실제 사용 기록으로 바꿔야 한다. 약한 아이의 결과는 5회 반복으로도 흔들림이 크다.
