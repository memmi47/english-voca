# C-003 오답 보기에 쓸 주제 자료를 점검하라

- 상태: 완료 (Draft PR 검토 대기)
- 담당 층: 실행 (Terra)
- 선행 카드: 없음
- 브랜치: `codex/theme-audit` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

뜻 고르기 카드의 오답 보기 하나를 "같은 주제·같은 품사"에서 뽑아도 되는지, 자료가 그럴 만한 품질인지 알게 된다.

## 배경

- `docs/LEARNING_VALUE_SPEC.md` 2.5절. 지금 오답 보기는 그림 종류(`type`)만 맞춘 무작위라 소거법으로 풀린다. 보기 2개 중 1개를 같은 주제에서 뽑으려 한다.
- `cards/data/catalogue.json`의 각 카드에 `theme`(예: "가족·사람·관계")과 `pos`가 있다. 혼동 묶음(`confusionGroups`)에 든 카드끼리는 오답으로 쓰지 않는다.
- 게임 쪽 구현은 T-006(Claude)이다. 이 카드는 자료 점검과 보고만 한다.

## 할 일

1. 주제별·품사별 카드 수 표를 만든다(대역 P1 / P2 / P3별로도).
2. 다음을 찾아 목록으로 낸다.
   - 주제가 비었거나 "기타"류에 몰린 카드.
   - 같은 주제·같은 품사 안에 오답 후보(혼동 묶음을 뺀 것)가 5개 미만인 카드.
   - 같은 주제 안에서 한글 뜻이 사실상 같은 말인 쌍(예: 큰 / 커다란). 이런 쌍이 오답으로 나오면 아이가 풀 수 없다. 혼동 묶음에 추가할 후보로 제안한다.
3. 제안: 주제를 그대로 써도 되는지, 묶음을 더 크게 합쳐야 하는지(예: 주제 2~3개를 한 군으로), 한 문단으로.

## 고칠 수 있는 파일

- 새 파일: `tools/audit_themes.py`, `docs/research/theme_audit.md`·`.csv`
- 혼동 묶음에 추가할 후보는 `tools/worlds/confusions.json`에 **넣지 말고** 보고서에만 적는다(추가는 사용자 확인 뒤).

## 바꾸면 안 되는 것

- `cards/data/*`, `reference/`, `cards/js/*`, `tests/*`.

## 완료 기준

```sh
python3 -I tools/audit_themes.py --check     # 보고서를 다시 만들어도 같은 결과
```

보고서에 위 1~3이 있고, 숫자마다 어떻게 셌는지 한 줄 설명이 있다.

## 결과

전체 4,610장 중 빈 주제·기타류(이름에 기타/보완) 200장, 후보 5개 미만 191장(뜻 고르기 109장), 같은 주제 뜻 검토 243쌍(기존 혼동 묶음 미공유 11쌍). 집계 방법과 카드별 목록은 보고서·CSV에 기록했다. `python3 -I tools/audit_themes.py --check` 2/2 파일 재현 일치. 실제 게임 필터와 정답률, 유사어 전수 검수는 확인하지 못함. 혼동 묶음 추가와 주제 통합은 사람 검토가 필요하다.
