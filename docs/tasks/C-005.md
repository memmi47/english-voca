# C-005 교차 검토: 기록 보호와 복습 규칙 변경을 읽고 문제를 찾아라

- 상태: 대기
- 담당 층: 설계 (Astra, 최고 노력 모드)
- 선행 카드: 없음
- 브랜치: `codex/review-c005` (기준 `claude/modest-mccarthy-3gadjk`). 보고서 파일만 추가한다.

## 목표

아이의 진행 기록이 사라지거나, 복습 규칙이 의도와 다르게 동작하는 경로가 남아 있으면 실사용 전에 드러난다.

## 배경

`docs/ORCHESTRATION.md`의 점검 C다. Claude가 만든 다음 변경을 상대편 설계 층이 읽는다. 작성자는 자기 코드의 빈틈을 잘 못 본다.

| 범위 | 파일 | 의도를 적은 문서 |
|---|---|---|
| 기록 보호 | `cards/js/store.js`, `cards/js/sync.js`, `tools/serve_cards.py`, `tools/backup_state.sh`, `cards/js/main.js`의 `loadRec`·`save`·`restore`·`paintSafety` | `docs/DATA_SAFETY.md` |
| 복습 부하 규칙 | `cards/js/map.js`(`RULES`, `batState`, `settleRun`), `cards/js/deck.js`(`planRun`, `_options`, `dueOrder`) | `docs/research/learning_load_sim.md` |
| 세계 진행 | `cards/js/world.js` | `docs/WORLD_SCHEMA.md` 4절 |

## 찾을 것

1. 기록이 줄거나 사라질 수 있는 경로. 예: 두 기기가 다른 형식 버전일 때, 저장 도중 탭이 닫힐 때, 서버가 꺼졌다 켜질 때, 합치기에서 한쪽 필드가 빠질 때, 접힌 판 기록(`past`)이 두 번 세어지거나 빠질 때, 서버의 거부 규칙을 정상 저장이 잘못 밟을 때.
2. `docs/DATA_SAFETY.md`가 약속했는데 코드나 테스트가 지키지 않는 것.
3. 보상(별·아이템·열쇠·도장·회오리)이 복습 일정이나 카드 등급을 바꾸는 경로. 있으면 안 된다.
4. 박쥐 게이지가 끝나지 않는 상태(시험을 마쳐도 계속 가득 참)나 아이가 아무것도 할 수 없는 상태(모든 칸이 막히고 박쥐 시험도 시작 못 함)가 되는 조건.
5. 세계 진행에서 칸을 건너뛰어 성에 가거나, 왕관·다음 대륙이 조건 없이 열리는 경로.
6. 시뮬레이션 보고서의 결론 중 가정에 지나치게 기대는 것.

## 내는 것

`docs/reviews/C-005.md` 한 파일. 문제마다: 심각도(기록 손실 / 진행 막힘 / 규칙 위반 / 사소함), 재현 조건(상태와 순서), 근거가 되는 파일과 줄, 고치는 방향 한 줄. 재현을 실제로 해 봤는지, 읽고 추론한 것인지 구분해 적는다. 문제가 없다고 본 항목도 무엇을 확인했는지 한 줄씩 적는다.

## 바꾸면 안 되는 것

- 코드와 테스트는 고치지 않는다. 고치는 일은 Claude 쪽 카드로 넘긴다. 재현용 스크립트는 보고서에 넣거나 `docs/reviews/` 아래에 둔다.
