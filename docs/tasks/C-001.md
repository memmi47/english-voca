# C-001 세계 설정값을 확정하고 기능어 집을 빼서 다시 생성하라

- 상태: 검토
- 담당 층: 실행 (Terra). 막히면 Sol.
- 선행 카드: 없음
- 브랜치: `codex/world-config-2` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

세계 파일이 사용자 결정(대륙 성 기준, 기능어 제외)을 담고, 게임이 그 파일을 초안 표시 없이 쓸 수 있는 상태에 한 걸음 가까워진다.

## 배경

- 대륙 성: 40장·75%, 다음 대륙을 여는 관문 유지 (`docs/research/learning_load_sim.md` 5절, 사용자 결정 2026-11-15·16).
- 기능어 121개는 학습 경로에서 뺀다 (`docs/LEARNING_VALUE_SPEC.md` 2.1절, 사용자 결정 2026-11-16). 학습 대상은 4,489장이 된다.
- 표현의 구성어 선행 관문은 두지 않는다. 게임에 그런 관문이 없고 표현은 일반 세계의 칸으로 이미 들어가 있다.
- 게임(`cards/js/world.js`)은 `finale.cards`·`finale.passRate`가 null이면 기본값 40·0.75를 쓰고, `sideActivities` 중 `kind: "sight"`는 T-001이 끝나면 화면과 왕관 조건에서 무시한다. 이 카드는 자료 쪽을 같은 상태로 맞춘다.

## 고칠 수 있는 파일

- `tools/worlds/config.json`, `tools/make_worlds.py`, `tools/check_world_generation.py`
- 생성 결과: `cards/data/worlds.json`, `cards/data/catalogue.json`, `docs/research/world_generation.md`
- `docs/WORLD_SCHEMA.md`, `docs/WORLD_GENERATOR_HANDOFF.md` (바뀐 내용만)

## 바꾸면 안 되는 것

- 카드 id, 세계 id(`p1-01` 등), 노드 id. 기존 칸의 단어 배정(기능어 집을 빼는 것 외에는 `assignmentSha256`의 근거가 되는 배정을 바꾸지 않는다. 바뀌면 이유를 결과에 적는다).
- `cards/js/*`, `cards/css/*`, `tests/*` (Claude 담당).
- `reference/` 원본.

## 할 일

1. `config.json`의 `continentCastle`을 `{"cards": 40, "passRate": 0.75}`로 넣는다. 세 대륙의 `finale`에 반영되고 `status`가 `pending-config`에서 벗어나야 한다.
2. `expressionPrerequisites`를 `"none"`으로 명시한다.
3. 기능어 집: 세계의 `sideActivities`에서 `kind: "sight"` 집을 만들지 않는다. 카드 121장은 `catalogue.json`에 남기되 어느 세계에도 배정하지 않고, 최상위에 `excluded: [{"reason": "function-words", "cardIds": [...]}]`로 적는다. `counts`는 배정 4,489 / 제외 121 / 합 4,610이 되게 한다.
4. `pending` 목록에서 끝난 항목을 뺀다: `runtime-v3-integration`, `sight-listen-spelling-support`, `continent-castle-config`, `expression-prerequisite-decision`. 남는 것: `actual-word-audio-validation`, `parent-sense-review`, `iPad-verification`. `playable`은 그대로 false.
5. 검사 스크립트가 새 수치(배정 4,489, 제외 121, 필수 집 0)를 확인하게 고친다.

## 완료 기준

```sh
python3 -I tools/make_worlds.py --check          # 통과
python3 -I tools/check_world_generation.py       # 통과, 배정 4,489 + 제외 121 = 4,610
node --test tests/*.test.mjs                     # 전부 통과 (고치지 않았으므로 그대로여야 한다)
node tests/cards_e2e.cjs                         # 전부 통과
```

브라우저 테스트의 "full deck: 4,610 cards" 검사는 카드 목록 전체 수를 본다. `catalogue.json`의 `words`가 4,610개로 남아 있으면 통과한다. 실패하면 테스트를 고치지 말고 결과에 적는다(Claude가 고친다).

## 막히면

기능어를 뺀 뒤 어떤 세계의 최단 경로에서 성 시험 12장을 채울 수 없으면 멈추고 그 세계 id를 적는다.

## 결과

- `python3 -I tools/make_worlds.py --check`: 통과. `python3 -I tools/check_world_generation.py`: 16/16 통과 (배정 4,489 + 제외 121 = 4,610, 필수 집 0).
- `node --test tests/*.test.mjs`: 58/58 통과. `node tests/cards_e2e.cjs`: 115/115 통과 (시스템 Chromium 사용, 전체 덱 4,610장 확인). 로컬 소켓 접근이 필요한 환경에서 실행했다.
- 기존 30세계의 map 전체를 기준 파일과 비교하여 노드와 카드 배정이 모두 같음을 확인했다. `assignmentSha256`은 해시에 포함된 기능어 집을 제거했기 때문에 바뀌었다. 카탈로그는 변경되지 않았다.
- 실제 음원·부모 뜻 검토·iPad 실기기 확인은 남아 있다. Claude 교차 검토 및 T-001 연결 확인이 필요하다.
