## 목표

빠르게 여러 번 보는 지금의 흐름은 지키면서, 문제 형식을 다양하게 해 반복해도 지루하지 않게 한다. 사용자는 구현보다 **설계 논의가 더 중요하다**고 했다(2026-11-20). 먼저 안을 사용자와 정하고, 확인을 받은 뒤 구현한다.

## 지금 상태 [verified 2026-11-20]

- 카드 형식은 둘: 직접 판단(알아요/몰라요, 새 단어)과 확인(뜻 3지선다). 규칙은 `cards/js/deck.js` (`Run`, `planRun`, `_options`), 화면은 `cards/js/main.js` (`showCard`, `front`, `optionButtons`, `judgeButtons`).
- 복습 간격 1·3·7·14·30일. "완전히 익힌 단어"는 `firmOf`(7일 단계 또는 금). 7일 단계부터 확인 카드만.
- 단어 4,610개: 명사 45%, 동사 15%, 표현(두 단어 이상) 384개, 길이 중간값 6글자. 그림(이모지) 0개, 예문 없음. 소리 파일은 저장소에 없고 기기 음성(speechSynthesis)이 대신 읽음.
- 긴 단어가 카드 칸을 넘으면 두 줄로 보임(사용자 지적).

## Claude가 낸 초안 (논의 출발점, 확정 아님)

| 기억 단계 | 지금 | 제안 형식 |
|---|---|---|
| 새 단어 | 앞면, 알아요/몰라요 | 그대로 + 소리 자동 재생 |
| 1·3일 복습 | 영어 → 뜻 3개 | 그대로, 가끔 소리 → 영어 고르기 |
| 7일 확인부터 | 같음 | 뜻 → 영어 고르기(방향 뒤집기) |
| 14·30일 | 같음 | 빠진 글자 1~2개 채우기(표현 제외) |
| 금 단어 | 거의 안 나옴 | 번개 집 O/X로만 |
| 한 판 중간 | 없음 | 4쌍 짝 잇기 카드 한 장 |

판단 틀: 같은 단어를 다른 방향으로 떠올리기(영→한, 한→영, 소리→글자)와, 기억이 굳을수록 조금 더 어려운 문제 [recall]. 재미 쪽은 형식이 바뀌는 리듬, 맞혔을 때 보이는 결과, 짧은 한 판.

## 정할 것 (사용자와 논의)

1. 형식 목록과 단계별 배치(위 초안을 바꿔도 됨).
2. 철자 형식에서 틀렸을 때 일정: 지금 규칙(다시 1일부터) 그대로인지, 한 단계만 내리는지. 바꾸면 `tools/sim_learning.mjs`로 복습 부하를 다시 재고 결과를 적는다.
3. 한 판의 속도 상한(카드 한 장 평균 시간)과 짝 잇기 같은 느린 형식의 횟수 제한.
4. 반대 가설 확인 방법: 지루함의 원인이 형식이 아니라 판 길이나 보상일 수 있다. 하루 카드 수, 형식별 정답률·시간, 중간에 그만둔 판 비율로 본다.

## 바로 해도 되는 것 (논의와 별개)

- 카드 위 영어 단어는 한 줄로 보인다. 칸보다 길면 글자 크기를 줄인다(최소 크기를 정하고, 그보다 작아져야 하면 그때만 줄바꿈). 브라우저 검사로 가장 긴 단어 몇 개를 확인한다.

## 바꾸면 안 되는 것

- 저장 형식과 기록 보호 규칙(`docs/DATA_SAFETY.md`): 몰랐던 기록(`miss`, `misses`, `lapses`)은 줄이지 않는다.
- 보상(별·아이템·꾸미기)은 일정과 등급을 바꾸지 않는다.
- 기존 검사를 지우거나 약하게 하지 않는다. `node tools/check_sim_baseline.mjs --update`는 일정 규칙을 바꾸기로 사용자가 정했을 때만, 그 이유를 결과에 적고 쓴다.

## 결과

### 승인한 형식과 1차 배치

사용자 결정(2026-11-20)으로 ‘뜻 → 영어 고르기’, ‘헷갈리는 두 단어 나란히’, ‘한 문장 속 뜻 고르기’를 추가한다. 기존 문제를 주로 풀다가 가끔 다른 형식을 만난다.

- 한 판을 기존 카드로 시작한다. 기존 카드 **6장**이 나온 뒤, 원래 뜻 확인을 하기로 잡힌 복습 카드 한 장의 화면을 바꾼다. 다음 새 형식까지도 기존 카드가 최소 여섯 장 나온다. 카드 순서와 장수는 원래 판이 정한다. 성·대륙 성·박쥐 시험, 첫 학습과 표본 확인에는 기존 화면을 쓴다.
- 새 형식을 시도하는 순서는 **뜻→영어 3 : 두 단어 비교 1 : 문장 속 뜻 1**이다. 판마다 시작 위치를 돌린다. 비교나 문장 차례에는 초반 몇 장에서 자료가 맞는 카드를 기다리고, 조건을 만족하는 카드만 바꾼다. 자료를 못 찾으면 기존 화면을 쓸 수 있어 실제 비율은 달라진다.
- 뜻→영어는 간단한 한 가지 뜻의 명사로 시작한다. 두 단어 비교는 직접 검토한 14쌍이며 이미 만난 두 단어를 놓고 비교한다. 문장 속 뜻은 단어장의 대표 뜻에 맞춘 짧은 예문 38개로 시작한다. 예를 들어 이 단어장의 `light`는 ‘불을 붙이다’이므로 ‘I **light** a candle.’을 쓴다.
- 채점과 복습 일정은 원래 카드와 같은 기록 경로를 쓴다. 비교 카드 답변은 그 판이 묻던 단어에만 적용한다. 새 화면의 오답은 ‘다음’을 누를 때까지 뜻을 보여 주고, 정답은 최대 1.1초 뒤 넘어간다. 먼저 누르면 바로 넘어갈 수 있고 발음은 답을 고른 뒤 들린다.
- 카드 영어 앞면은 가능한 한 한 줄로 표시한다. 좁은 창에서도 28px까지 줄여 보고, 거기서도 한 줄에 안 들어갈 때 줄바꿈한다. 카드 뒷면의 작은 영어에 쓰는 최소 크기는 22px이다.
