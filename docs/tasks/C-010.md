# C-010 음악을 90년대 PC 게임 감성의 미디(General MIDI)로 바꾸고 세계마다 변화를 줘라

- 상태: 구현·자동 검사 완료, 기기 청취 확인 대기
- 담당 층: 설계 (Astra: 곡 구성과 악기 배정) → 구현 (Sol: 생성기, 녹음, 재생 코드)
- 선행 카드: 없음
- 브랜치: `codex/gm-music` (기준 `claude/modest-mccarthy-3gadjk`)

## 목표

게임 음악이 픽셀 그림과 어울리는 90년대 PC 게임·교육용 CD 게임 느낌(피아노, 마림바, 플루트, 현악, 금관, 드럼 같은 General MIDI 악기 소리)이 된다. 같은 대륙 안에서도 세계마다 조금씩 다르게 들려 몇 달을 해도 덜 질린다.

## 배경 (사용자 결정 2026-11-17)

- 사용자: "90년대 등 옛날 감성의 미디". 지금 음악은 80년대 게임기식 칩튠(사각파·삼각파·잡음, `cards/js/chip.js`)이라 원하는 소리가 아니다.
- 지금 구성 [verified]: 대륙 곡 3개(meadow 112BPM, sea 96, sky 88, 각 24마디 반복, 약 51~65초), 화면 곡 3개(study 카드, castle 성·박쥐, play 놀이집·번개), 짧은 곡 6개(clear, victory, key, item, grade, bat). 생성기 `tools/build_postal_music.py`가 음표 자료(`cards/assets/postal/music/*.json`)와 같은 내용의 미디 파일(`assets/post-office/v2/midi/*.mid`)을 만든다. 화면은 `cards/js/main.js`의 `G.sound.scene(id)`·`jingle(id)`로 고르고, 재생은 `cards/js/sound.js`의 `Sound`가 한다(단어 소리가 날 때 음악을 줄이는 `duck` 포함).
- 한 대륙 안의 세계 8~15개가 같은 곡을 쓴다. 대륙 2는 기준 아이가 약 30주 동안 진행한다 [estimate: 시뮬레이션의 대륙 성 도착 7주 → 37주].
- 회오리 판은 카드 공부 곡을 쓰고 전용 곡·징글이 없다. 대륙 성(40장 관문)과 세계 성이 같은 곡이다.

## 방식 (설계 층 결정)

브라우저에서 미디를 직접 연주하지 않는다(외부 라이브러리와 큰 음색 파일을 매번 실어야 한다). 대신:

1. 곡을 Standard MIDI File로 쓴다. 트랙마다 General MIDI 악기 번호(Program Change)를 정하고, 드럼은 10번 채널을 쓴다. 4~8 트랙.
2. 무료로 배포가 허용된 GM 사운드폰트로 미리 녹음한다(예: FluidSynth + GeneralUser GS 또는 FluidR3_GM [recall: 둘 다 녹음 결과 배포가 허용되는 것으로 알고 있음. 실제 라이선스 문서를 읽고 결과에 인용한다]). 라이선스를 확인하지 못한 사운드폰트는 쓰지 않는다. 사운드폰트 파일 자체는 저장소에 넣지 않는다(녹음할 때만 쓴다). 쓴 사운드폰트의 이름·버전·내려받은 주소·라이선스를 `docs/research/music_gm.md`에 적는다.
3. 녹음 결과를 AAC(`.m4a`, 44.1kHz, 스테레오, 96~128kbps)로 `cards/assets/postal/music-gm/`에 둔다. iPad Safari가 재생할 수 있어야 한다.
4. 반복 곡은 이음매가 들리지 않아야 한다: 재생은 Web Audio(`decodeAudioData` → `AudioBufferSourceNode`, `loop = true`, `loopStart`·`loopEnd`)로 하고, 반복 구간은 마디 수와 템포로 계산한 길이에 인코더가 앞에 붙이는 무음 길이를 더해 맞춘다. 녹음은 반복 구간 뒤에 한 마디 이상 여유(잔향 꼬리)를 둔다.
5. 녹음 파일이 없거나 불러오지 못하면 지금의 칩튠 곡으로 돌아간다(오류 화면 없음). 짧은 효과음(`sfx.json`, 발소리·도장 등)은 지금 칩튠 그대로 둔다.

## 곡 구성 (Astra가 정해 `docs/research/music_gm.md`에 적는다)

- 모두 새로 쓴 곡이어야 한다. 실제 게임·방송·광고 음악의 선율, 화성 진행의 특징적인 부분, 제목을 흉내 내지 않는다. 지금 칩튠 곡의 선율을 다시 편곡해도 된다(우리가 쓴 곡이다).
- 대륙 곡 3개는 각 32마디 이상 반복(지금 24마디보다 길게). 분위기 예시(정해진 것은 아니다): 새싹 들판 = 마림바·플루트·어쿠스틱 기타·피치카토, 굽이굽이 바다 = 스틸 드럼·비브라폰·현악 패드·베이스, 별빛 하늘 = 첼레스타·뮤직박스·패드·부드러운 합창.
- 세계별 변화: 대륙 곡 하나에서 세계마다 다른 판을 만든다(세계 30개 = 판 30개). 세계 번호로 다음 중 둘 이상을 정한다: 조 옮김(±2반음 안), 템포 ±8% 안, 주선율 악기, 반주 형태(아르페지오/코드/베이스 리듬), 드럼 유무. 같은 대륙의 이웃한 두 세계는 주선율 악기가 달라야 한다.
- 화면 곡: 카드 공부(조용하고 단어 소리를 가리지 않게, 중저음 위주, 주선율은 단순하게), 세계 성, 대륙 성(세계 성보다 웅장하게: 금관·팀파니), 놀이집·번개, 회오리 판(경쾌하고 약간 긴박하게).
- 짧은 곡: 지금 6개를 같은 악기 세계로 다시 쓰고, "회오리에 휩쓸렸어요" 1개를 더한다.
- 곡마다 크기를 맞춘다(같은 체감 음량, 정규화 목표를 적는다). 단어 소리가 늘 더 커야 한다.

## 연결 (화면 코드)

- `cards/js/sound.js`: 녹음 파일 재생기를 더한다. `scene(id)`가 `id`에 맞는 녹음 파일을 찾고, 없으면 칩튠으로 돌아간다. `duck`, 음악 켜기·끄기(`setMusic`), 검사가 읽는 `seen`(예: `scene:meadow`)은 지금과 같은 이름·뜻으로 유지한다.
- `cards/js/main.js`: 세계 지도 곡을 대륙 곡 대신 세계 판으로(`scene('meadow')`처럼 대륙 id를 그대로 남기고 세계 판은 별도 값으로 넘기거나, 검사의 `scene:<대륙>` 기록이 그대로 남게 한다). 대륙 성은 대륙 성 곡, 회오리 판은 회오리 곡, 휩쓸렸을 때 징글.
- 곡 목록은 `cards/assets/postal/music-gm/manifest.json` 하나에 둔다(곡 id → 파일, 반복 시작·끝 초, 음량).

## 바꾸면 안 되는 것

- 규칙 코드(`deck.js`, `map.js`, `world.js`, `store.js`, `sync.js`, `storm.js`), 저장 형식, `cards/data/*`, `reference/`.
- 지금 칩튠 자료(`cards/assets/postal/music/*.json`, `sfx.json`)와 `cards/js/chip.js`는 지우지 않는다(되돌아갈 곳이다).
- 음악 기본값(꺼짐)과 기기별 설정 키 `cards.v0.pref`.
- 기존 검사를 지우거나 약하게 하지 않는다.
- 유료 도구·유료 음원·유료 사운드폰트를 쓰지 않는다. 사운드폰트 파일을 저장소에 넣지 않는다.

## 완료 기준

```sh
python3 -I tools/build_postal_music.py              # 미디·음표 자료 생성
bash tools/render_music.sh <사운드폰트 경로>          # 녹음·인코딩. 다시 실행해도 같은 목록
node tools/check_postal_music.cjs                   # 통과. 새 검사: manifest의 모든 곡 파일이 있고 길이·반복 구간이 맞음
node --test tests/*.test.mjs                        # 전부 통과
node tests/cards_e2e.cjs                            # 전부 통과 (지금 149)
node tools/check_sim_baseline.mjs                   # 그대로
du -sh cards/assets/postal/music-gm                 # 결과에 적는다. 40MB를 넘으면 멈추고 적는다
```

새 브라우저 검사:

1. 음악을 켜고 대륙 1의 두 세계 지도를 차례로 열면 서로 다른 녹음 파일이 재생된다(그리고 `scene:meadow`는 그대로 기록된다).
2. 녹음 파일 요청을 막으면 칩튠으로 재생되고 오류 화면이 없다.
3. 카드 판에서 단어 소리가 날 때 음악이 줄어든다(`duck`).
4. 반복 곡의 `loopStart`·`loopEnd`가 manifest 값과 같다.

## 막히면

- 이 환경에서 사운드폰트나 FluidSynth를 받을 수 없으면: 작곡(미디)과 재생 코드, 녹음 스크립트까지만 하고 녹음은 "Mac에서 `brew install fluidsynth` 뒤 실행"으로 결과에 적는다. 녹음 파일이 없어도 게임은 칩튠으로 동작해야 한다.
- 라이선스가 녹음 결과의 배포를 허용하는지 확인할 수 없으면 그 사운드폰트를 쓰지 않는다.
- 카드에 없는 결정이 필요하면 추측하지 말고 멈춘 뒤 여기에 질문을 적는다.

## 결과

설계를 [Draft PR #12](https://github.com/memmi47/english-voca/pull/12)에 먼저 게시한 뒤 Sol 구현을 진행했다. 새 MIDI 45개(대륙 원곡 3 + 실제 녹음 대응 42), AAC 42개(세계 30 + 화면 5 + 징글 7), manifest·렌더러·GM 재생/칩튠 폴백·단어/징글 duck을 완성했다. 화면 코드는 음악 선택 줄만 바꿨다.

- `python3 -I tools/build_postal_music.py`: 통과. 최종 manifest와 MIDI 45개 재생성 후 byte 동일. 기존 칩튠 JSON/SFX/v2 MIDI 및 규칙·자료 등 보호 대상 43개 SHA 동일.
- `bash tools/render_music.sh <SF2>`: GeneralUser GS 2.0.3, FluidSynth 2.4.4, FFmpeg 7.1.5로 42개 실제 녹음 완료. 폰트 자체는 Git 밖.
- `node tools/check_postal_music.cjs`: 기존 칩튠 12곡·SFX 16개 + GM 42개 통과. MP4 movie timescale 44,100으로 편집 목록 길이 반올림을 해결해 모든 브라우저 frames가 manifest와 일치한다.
- `node --test tests/*.test.mjs`: 100/100.
- `node tests/cards_e2e.cjs`: 153/153(기존 149개 변경 없이 GM 검사 4개 추가), 최종 AAC에서 재확인.
- `node tools/check_sim_baseline.mjs`: 출력 동일, 기준 파일 갱신 없음.
- `du -sh cards/assets/postal/music-gm`: 34M, 실제 35,097,239 bytes(40MB 미만).

AAC는 44.1kHz stereo 96kbps, raw priming 1,024 samples/실측 잔여 지연 0, 반복곡 −24.1..−24.0 LUFS·공부곡 −27.1 LUFS, 징글 RMS 약 −24dBFS, 최대 true peak −7.4dBTP, clipping 0이다. 실제 decode seam 검사를 통과했다. 상세 출처·라이선스·측정·실행 환경은 [음악 설계와 결과](../research/music_gm.md)에 기록했다. iPad/mac 실제 청취는 위 사용자 확인 목록으로 남긴다.
