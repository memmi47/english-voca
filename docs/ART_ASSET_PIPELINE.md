# 우편 여행 아트·음악 v1 (2026-11-13)

현재 결과물은 **공통 에셋 + 두 세계의 별도 작동 체험**이다. 기존 게임 파일을 바꾸거나 실제 기록·음성 파일을 덮어쓰지 않는다. `showcase/post-office`는 기존 `Run`과 `Sound`를 가져다 쓰되 별도 메모리 상태로 움직인다. 전체 어휘 생성 결과나 30세계의 최종 완성본이 아니다.

## 그림체와 제작 규격

청록 모자·크림 셔츠·갈색 가방의 성별을 고정하지 않은 우편배달 친구. 두 아이 구분은 청록/금색 모자 색이다. 잉크 `#233F3A`, 청록 `#387D74`, 크림 `#FFF0CA`, 코럴 `#CC6651`, 금색 `#EAB65C`, 물 `#7BC4D0`를 공통으로 쓴다. 목표 영어는 또렷한 둥근 글꼴, 화면 틀은 기존 Galmuri다.

생성된 컨셉 보드는 그림체 참고용이다. 실제 게임 에셋은 소스에서 직접 그린 단색·정수 좌표 SVG이며 컨셉 보드를 잘라낸 이미지가 아니다. 참고 이미지와 실제 SVG의 세밀함은 같지 않다. 현재 SVG는 작은 화면에서 구분되는 실루엣과 재사용성을 우선한 1차 제작본이다.

| 구분 | 납품 내용 | 규격 |
|---|---|---|
| 캐릭터 | 2색 × 5프레임 = 10 symbol | 48×48, idle / walk1 / walk2 / happy / wave. 동작은 4종, 걷기는 2프레임 |
| 지형 | grass / water / path / bridge | 64×64, 반복 무늬와 다리 |
| 풍경 | tree / bush / flowers / rock / reeds / lily | 48 또는 64, 투명 배경 |
| 건물 | post-office / playhouse / gate / mailbox / sign | 48 또는 64 |
| 친구 | leaf / cloud / snail / bat | 48×48, 1차 정지 원형. 친구별 독립 애니메이션은 아직 없음 |
| UI | envelope / star / key / stamp / sound / footstep / flag / flower-badge | 32×32 |
| 합계 | **37개 SVG symbol** | `assets/post-office/v1/sprites.svg`, 목록은 manifest.json |

정수 배율 확대를 우선하고 `shape-rendering: crispEdges`를 보존한다. 작은 카드와 영어 단어의 읽기 쉬움을 픽셀 장식보다 우선한다. 뜻·단어 그림은 응답 전 카드 전면에 미리 보여 주지 않는다. 친구 표정·도장은 기억 등급과 구분한다.

## 음악과 효과음

[verified] 두 개의 짧은 원작 루프(들판/놀이), 각 MIDI 멜로디 원본과 AAC 재생 파일, WAV 효과음 8종을 제작했다. 새 단어 발음 파일이 아니다. 사람 녹음이나 검수 완료 음원이라고 표시하지 않는다.

- `meadow.mid / meadow.m4a`: 지도용, 108 BPM, 약 18초.
- `play.mid / play.m4a`: 놀이용, 116 BPM, 약 17초.
- `tap, step, flip, correct, retry, stamp, gate, mail.wav`: 이동·카드·놀이의 짧은 반응음.
- MIDI는 편집 원본이며 게임에서는 AAC를 재생한다. 편곡 소스는 build_postal_assets.py다. MIDI와 AAC는 같은 멜로디이며 AAC에는 단순 저음 반주가 더해진다.
- 음악 기본은 꺼짐. 사용자가 켜고 음악/효과음을 따로 끈다. 음성 재생 중 음악을 낮추고 효과음을 멈춘다. 파일 ended 또는 기기 음성 end에서 음악을 복구하며 중단·재생 오류도 복구한다.
- 음량·분위기·반복 피로감은 실제 iPad·아이 사용에서 확인해야 한다. AAC는 브라우저 재생·메타데이터 확인까지이며 스피커 청취 검수와 다르다.

## 두 세계 체험 범위

- `문 앞 꽃밭`, `둥실 연못`: 기존 지도 v3의 큰길·우회로·놀이집을 새 그래픽으로 표시하고 캐릭터가 길을 따라 걷는다.
- 세계마다 **시제품의 30단어**, 칸마다 2단어. 전체 두 세계는 중복 없는 시제품 60단어를 사용한다. 기능어 집·실제 박쥐 시험·전체 저장/동기화는 이 체험에서 연결하지 않았다. 생산용 세계의 142/141개 어휘를 배정한 결과가 아니다.
- 기존 `cards/js/deck.js`의 Run·복습 규칙을 그대로 가져와 소리→응답→뜻 공개→재도전을 실행한다. 체험 프로필 두 개는 메모리에서 분리하고 기존 localStorage나 Mac state API에 쓰지 않는다.
- 체험성은 빨리 끝까지 확인할 수 있도록 **6장·80%**다. 실제 세계 성 **12장·80%** 규칙을 변경한 것이 아니며 화면에도 체험성을 명시한다.
- 선택 놀이집 1: SVG 그림 짝 맞추기 3쌍. 선택 놀이집 2: 우체통이 노란 영역에 왔을 때 편지 보내기 3회. 시간 상한·목숨·실패 벌점이 없고 다시 시도할 수 있다. reduced-motion에서는 우체통을 중앙에 둔다.
- 놀이집 최초 완료는 장식 도장만 추가한다. 복습 일정·카드 등급·학습 칸 완료·실제 별·열쇠를 바꾸지 않는다. 같은 프로필의 같은 놀이집 도장은 중복 추가하지 않는다.

## 실행과 납품

```sh
python3 -I tools/build_postal_assets.py
python3 tools/serve_art_lab.py
# http://127.0.0.1:8093/showcase/post-office/

# Mac의 준비된 단어 파일 연결
python3 tools/serve_art_lab.py --audio-dir /단어음원/폴더 --host 0.0.0.0
# 폴더: manifest.json 및 그 안의 files[card_id]가 가리키는 파일

python3 -I tools/package_postal_showcase.py --output /tmp/postal-showcase
# postal-demo.html: 서버 없이 여는 단일 HTML (기기 음성, 미디어 내장)
# postal-asset-kit.zip: SVG·MIDI·AAC·WAV·소스·폰트 라이선스·문서
```

단어 음성은 사용자가 Claude와 Mac에서 준비했다고 알렸다. 이 체크아웃에는 실제 manifest/단어 파일이 없으므로 해당 파일의 음질·전체 매핑을 직접 확인하지 못했다. 서버의 `/voice/`를 별도 폴더에 연결해 준비된 파일을 그대로 쓸 수 있다. 음원에 없는 카드는 기존 Sound의 미국식 기기 음성을 시도하며, 실패하면 응답 버튼을 잠그고 부모가 명시적으로 ‘소리 없이 체험’을 선택한 경우만 parent_skip로 기록한다.

## 검증과 다음 관문

`node tools/check_postal_showcase.cjs /tmp/postal-showcase`는 전용 테스트 음원(합성 톤)을 임시 폴더에 만들고 읽기 전용 서버로 검사한다. 실제 영어 발음 검수로 세지 않는다. 오디오 파일 연결·실패·Range, 카드 전면 정답 숨김, 두 프로필 분리, 두 미니게임·도장 중복·학습 불변, 체험성, 390px 스크롤, 무수정 state API를 확인한다.

다음 관문은 Mac의 실제 음성 파일을 연결한 iPad 재생, 두 아이가 길/놀이를 고르는 관찰, 실제 주간/전체 어휘 배정과 저장·동기화 연결이다. 소리·시각·재미가 확인되면 나머지 지형 네 세트와 친구 반응 애니메이션으로 확장한다.
