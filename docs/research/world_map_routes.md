검사: 시작과 성 연결, 모든 학습 칸이 어느 성 경로에 속함, 무료 노드만으로 성 도달 불가, 빈 학습 칸·고립 노드·중복 선 없음, 칸당 1~10장. 놀이집은 직행 구간보다 학습 칸이 많은 우회로에 붙이고, 게임 완료 여부는 성 접근·왕관·복습·등급과 무관하다.

기능어 121개와 P3 표현 2개는 별도 필수 집이며 총 배정 목표 4,610개를 유지한다. 모든 어휘를 만나는 왕관에는 학습 칸·필수 집이 필요하지만 미니게임은 포함되지 않는다. 도장은 장식용이며 별·열쇠·단어 등급을 주지 않는다.

여섯 지형 틀을 세계에 맞춰 반사·축척·배치해 미리보기를 만든다. 30개를 서로 완전히 다른 손그림으로 만들었다고 주장하지 않는다. 재미와 아이 선호는 실제 사용 전 가설이다.
