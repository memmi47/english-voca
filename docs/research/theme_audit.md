## 검토 목록

- 빈 주제 또는 기타류: **200장**. 빈 값, 이름에 `기타` 또는 `보완`이 들어가는 주제를 기계적으로 선택했다. CSV의 `빈값·보완` 행에 카드별로 적었다. 명칭 기준이므로 광범위한 다른 주제는 포함하지 않는다.
- 후보 5개 미만: 전체 **191장**, 그중 뜻 고르기 **109장**. 같은 주제·정확히 같은 품사 문자열에서 자기 자신, 뜻이 없는 카드, 듣기 전용 카드, 공유 혼동 묶음이 있는 카드, 표시 한글 뜻이 정확히 같은 카드를 제외한 나머지를 센다. 대역은 제한하지 않는다. CSV에 카드와 후보 수를 적었다. 실제 게임의 추가 필터는 적용하지 않았으므로 상한에 가깝다.
- 같은 주제 뜻 검토: **243쌍**, 그중 기존 혼동 묶음을 공유하지 않는 **11쌍**. 서로 다른 카드의 한글 뜻을 양끝 공백 제거 후 정확히 비교하고, 코드에 명시한 아홉 수동 유사어 쌍도 비교했다. 품사와 대역은 제한하지 않는다. CSV에 양쪽 카드·근거·기존 묶음 공유 여부를 적었다. 기계적 후보일 뿐 문맥상 동의어 여부는 사람이 확인해야 하며, 이 방법은 유사어 전수 검사가 아니다.

## 제안

현재 주제·품사만으로 모든 카드에 다섯 후보를 보장할 수 없으므로 그대로 일괄 적용하기보다 후보가 부족할 때 기존 방식으로 되돌리는 방안을 T-006에서 검토한다. 주제를 일괄 합치면 관계없는 보기가 늘 수 있어 현재 수치만으로 합칠 군을 결정하기 어렵다. CSV의 부족 목록과 뜻 검토 쌍을 사람이 확인하고, 혼동 묶음 추가와 군 통합은 별도 결정한다. 실제 정답률과 추가 필터에 따른 후보 수는 아직 확인하지 못했다.
