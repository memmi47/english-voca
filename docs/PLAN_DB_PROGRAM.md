# 단어 DB 학습 프로그램 기획안

작성일 2026-11-11, 개정 2026-11-12(플래시카드를 기본 형태로, 소리 먼저, 예문과 음성 인식 제외). 대상: 초등 저학년 남매, iPad, 하루 15분. 기존 `game/`(장면 탐험·탐정형)은 그대로 두고 별도 프로그램으로 새로 만든다는 전제다.

표기: [verified] 이번 작업에서 DB·코드·검색으로 확인. 웹 출처는 검색 결과 요약을 읽은 것이고 원문 전체를 열람하지는 않았다. [recall] 기억에 의존. [estimate] 계산·추정이며 방법을 함께 적는다.

## 0. 요약

- 기본 형태는 플래시카드다. 단어와 소리가 먼저 나오고, 아이가 "알아요" 또는 "몰라요"를 누르면 뜻이 공개된다. 카드 한 장에 약 4초, 하루 15분에 약 200장을 본다 [estimate, 8절].
- 기존 "주간 팩 10~15개 + 장면 그림" 속도로는 DB의 모르는 단어 약 3,000개에 256주가 걸린다 [estimate]. 플래시카드는 시간만 보면 하루 새 단어 15개까지 들어간다. 그래서 상한은 시간이 아니라 아이의 기억이 정한다. 하루 10개로 잡으면 P1 8주, P1+P2 35주, 전체 50주다 [estimate].
- 많이 보는 것만으로는 남지 않고, "알아요"라는 자기 판단은 부풀려진다. 그래서 뜻 3개 중 고르는 확인 카드를 섞고, 7일 이후의 복습은 항상 확인 카드로 한다.
- 재미는 카드 위에 얹는다. 단어 카드의 등급과 도감, 판마다 보스 게이지와 연속 정답, 주간 가족 보스. 카드 넘기는 시간을 늘리지 않고 그림 제작도 없다.
- 만들 자산은 단어 음성 4,763개뿐이다. 예문과 음성 인식은 범위에서 뺐다.
- 흥미와 디자인은 문서로 확정할 수 없다. 단어 60개 시제품을 두 아이가 3회 써 보는 관문을 첫 단계에 둔다.

## 1. 문제 재정의

### 1.1 왜 양이 필요한가

- 읽기 이해에 필요한 아는 단어 비율은 최소 95%, 적정 98%로 본다 [verified: Laufer 계열·Hu & Nation 인용, 16절]. 단, 뚜렷한 문턱이 있다는 데는 반론이 있다(Schmitt 외 2011).
- Geronimo Stilton은 Lexile 410L~650L이고 확인한 권들은 대체로 8,000~10,000단어다(긴 권은 2만 단어 이상) [verified: 16절]. 10,000단어 책에서 95%는 모르는 단어 500회, 98%는 200회 등장을 뜻한다 [estimate: 10,000 × 5%, 2%].
- 어린이 글의 약 90%는 고빈도 약 874어(New Dolch List, 90%는 v1.0 875어 기준 수치)로 덮인다 [verified: 16절]. DB에는 이 중 856어가 있고 모두 P1이다 [verified: DB]. 즉 90%까지는 수백 단어로 가지만, 90%에서 95~98%로 가는 구간은 빈도가 낮은 수천 단어가 필요하다.
- 결론: 주 10~15개로는 P1을 마치는 데도 여러 해가 걸리고, 책의 미지어 비율은 거의 움직이지 않는다. 필요한 것은 하루 처리량이다.

### 1.2 전달 경로

빈도 분포(소수의 단어가 대부분의 등장을 차지) → 학습 순서가 책 기여도를 결정 → 하루에 넘기는 카드 수와 아이가 감당하는 새 단어 수가 속도를 결정 → 새 단어 수가 미지어 비율의 하락 속도를 결정 → 쪽당 모르는 단어 수(기존 성과 지표)가 내려감.

## 3. 목표와 성공 기준

| 구분 | 기준 | 측정 |
|---|---|---|
| 1차 목표 | P1 1,215개를 "익힘" 상태로 | 프로그램 기록 |
| 2차 목표 | P1+P2 3,525개 | 프로그램 기록 |
| 최종 지표 | 실제 책에서 쪽당 모르는 단어 4주 내 3개 이하, 8주 내 2개 이하 (기존 주간 도구의 기준 유지) | 사전학습하지 않은 쪽을 부모가 주 1회 기록 |
| 과정 지표 | 분당 카드 12장 이상, 확인 카드 정답률 80~90%, 주간 거부 1회 이하 | 프로그램 기록 + 부모 기록 |

"익힘"의 정의: 1·3·7·14·30일 복습을 연속 통과하고, 7일 이후 단계를 확인 카드(뜻 고르기)로 통과한 상태.

## 4. 설계 원칙

1. 카드를 넘기는 것이 진행이다. 세션 시간의 90% 이상이 카드에 쓰인다.
2. 아는 단어는 빨리 지나간다. 한 번 보고 "알아요"면 두 번의 확인만 남는다.
3. 순서는 책 읽기 기여도가 정한다. 주제 묶음이나 알파벳이 아니다.
4. 카드당 자산은 음성과 한글 뜻, 있으면 이모지다. 직접 그리는 그림과 예문은 없다.
5. 게임 요소는 카드 위에 얹는다. 카드 넘기는 시간을 늘리는 요소는 넣지 않는다.

## 5. 학습 모델

### 5.1 카드 한 장

| 순서 | 화면 | 시간 [estimate] |
|---|---|---:|
| 1 | 앞면. 영어 단어가 크게 나오고 소리가 자동으로 난다 | 약 1초 |
| 2 | 아이가 "알아요" 또는 "몰라요"를 누른다 (좌우로 밀어도 됨) | 약 1.5초 |
| 3 | 뒷면. 한글 뜻과, 있으면 이모지. "알아요"였으면 1초 뒤 자동으로 다음 카드, "몰라요"였으면 소리를 한 번 더 들려주고 2.5초 | 1~2.5초 |

- 뜻은 아이가 판단한 뒤에 공개한다. 답을 먼저 보여 주지 않는다는 요구는 유지된다.
- 확인 카드: "알아요"를 누른 카드 중 일부는 뜻을 바로 보여 주지 않고 한글 뜻 3개 중에서 고르게 한다. 약 5.5초. 비율은 3장 중 1장에서 시작하고, 확인 정답률이 90% 이상이면 6장 중 1장으로 줄이며, 75% 미만이면 매번 확인한다.
- 확인 카드의 오답 보기에서는 같은 한글 뜻 712장과 발음이 같은 단어를 서로 제외한다.

### 5.2 단어 하나가 거치는 길

| 상황 | 처리 |
|---|---|
| 처음 만남, "알아요" (확인이 걸렸으면 통과) | "아는 듯"으로 분류. 7일 뒤와 30일 뒤에 확인 카드. 둘 다 통과하면 익힘 |
| 처음 만남, "몰라요" 또는 확인 실패 | 같은 판에서 3장 뒤, 8장 뒤, 판 끝에 다시 나온다. 마지막에 "알아요"면 1일 뒤 복습 |
| 복습 1일, 3일 | 일반 카드(자기 판단). 일부는 확인 카드 |
| 복습 7일, 14일, 30일 | 항상 확인 카드 |
| 복습에서 "몰라요" 또는 확인 실패 | 5.4의 규칙 |

- 한 판에 새로 들어오는 단어에는 뜻이 비슷한 단어를 함께 넣지 않는다. 기존 요구(유사어는 처음에 따로 만난다)와 같다.
- 책 표본이 등록된 단어는 뒷면에 책 문장을 작게 보여 준다. 없으면 뜻만 나온다.

### 5.3 카드 종류

| 종류 | 내용 | 쓰는 곳 |
|---|---|---|
| 일반 카드 | 단어 + 소리 → 알아요/몰라요 → 뜻 | 대부분 |
| 확인 카드 | 단어 + 소리 → 한글 뜻 3개 중 고르기 | "알아요"의 일부, 7일 이후 복습 전부 |
| 번개 카드 | 단어와 뜻 한 쌍 → 맞다/아니다 | 세션 끝 1분, 익은 단어 |
| 듣고 글자 고르기 | 소리 → 영어 단어 3개 중 고르기 | 한글 뜻이 없는 기능어 121개 |
| 철자 | 소리 + 뜻 → 글자 타일 | 부모가 고른 단어만, 1차 범위 밖 |

### 5.4 복습 규칙

- 간격은 요구대로 1·3·7·14·30일이다. 같은 카드는 하루 한 번만 채점한다.
- 틀렸을 때의 처리는 결정이 필요하다(12절 D4). 현재 규칙은 "처음으로 되돌림"이다.
- 하루 새 단어 수는 고정하지 않는다. 확인 카드 정답률이 80% 아래로 내려가거나 다음 날 복습이 세션 용량을 넘으면 줄이고, 90%를 넘으면 늘린다. 범위 4~15개.

## 6. 하루 15분의 구성

| 구간 | 시간 | 내용 |
|---|---:|---|
| 시작 | 15초 | 소리 켜기 1탭 |
| 1판 | 4분 30초 | 카드 약 65장. 새 단어와 만기 복습을 섞음 |
| 2판 | 4분 30초 | 카드 약 65장 |
| 3판 | 4분 | 카드 약 60장. 남은 복습 위주 |
| 번개 | 1분 | 익은 단어 맞다/아니다, 자기 기록 표시 |
| 마무리 | 20초 | 오늘 등급이 오른 카드, 도감 |

- 판마다 10초짜리 결과 화면에서 멈출 수 있다. 한 번에 15분을 못 하는 날은 판 단위로 나눠 한다.
- 새 단어는 앞쪽 판에 두고, 복습은 새 단어의 재등장 사이를 벌려 주는 용도로 섞는다.
- 시간이 모자라면 잘리는 것은 3판의 복습 꼬리와 번개다.

## 7. 학습 순서

대기열 순서는 아래 기준을 위에서부터 적용한다.

1. 이번 주 책 단어. 부모가 주간 도구에 책 표본을 등록하면 그 책의 모르는 단어가 맨 앞으로 온다. 하루 새 단어의 절반까지 차지한다.
2. 등록된 책들에서의 누적 등장 수(주간 도구의 corpus 값).
3. NDL 순위(어린이 글 기준, 856개).
4. NGSL 순위(2,024개).
5. Cambridge YLE 단계(Starters → Movers → Flyers).
6. P1 → P2 → P3.

- 빈도 근거가 없는 2,281개(P3 전부 포함)는 대역 안에서 주제를 돌려 가며 낸다. 공개 빈도 목록으로 순위를 보충하는 방법이 있으나 어떤 목록을 쓸지는 정하지 않았다.
- 1순위 뜻만 먼저 돈다. 2순위 이하 1,818장은 책에서 그 뜻이 등장했을 때, 또는 1순위 뜻을 익힌 뒤에 넣는다.
- 장르 단어 34개(ghost, rodent, whisker 등)는 Geronimo 계열에서 자주 나올 것으로 보고 P1 뒤에 바로 붙인다.

## 8. 처리량 시나리오

### 8.1 계산 방법 [estimate]

- 하루 순수 카드 시간 = 900초 - 전환·시작·마무리 90초 = 810초.
- 카드당 평균 시간 = 일반 카드 3.5초와 확인 카드 5.5초를 3:1로 섞어 4.0초.
- 30일 간격에 도달하려면 복습 5회를 연속으로 통과해야 한다. 통과율 p, 틀리면 처음으로 돌아갈 때 필요한 복습 횟수의 기댓값 = (p^-5 - 1) / (1 - p).
- 모르는 단어 1개의 비용 = 첫 공개 때 추가 3초 + (당일 4회 + 복습 기댓값) × 카드당 시간.
- 아는 단어 1개의 비용 = 3회 × 카드당 시간.

### 8.2 시간만 본 시나리오

| | 약세 | 기준 | 강세 |
|---|---:|---:|---:|
| 카드당 시간 | 5.5초 | 4.0초 | 3.2초 |
| 복습 통과율 | 78% | 85% | 90% |
| 이미 아는 비율 P1 / P2 / P3 | 40 / 15 / 5% | 60 / 30 / 15% | 75 / 45 / 25% |
| 주당 학습일 | 5일 | 6일 | 6일 |
| 하루에 보는 카드 | 147장 | 202장 | 253장 |
| 모르는 단어 1개 비용 | 87초 | 52초 | 38초 |
| 시간상 가능한 하루 새 단어 | 9.4개 | 15.4개 | 21.3개 |
| P1 완료 | 18주 | 7주 | 4주 |
| P1+P2 완료 | 61주 | 26주 | 16주 |
| 전체(P3 보류분 제외 4,610개) 완료 | 83주 | 37주 | 23주 |

- 기준 검산: 복습 기댓값 (0.85^-5 - 1) ÷ 0.15 = 8.36. 비용 3 + (4 + 8.36) × 4.0 = 52.4초. 810 ÷ 52.4 = 15.4개. P1은 모르는 486개 × 52.4초 + 아는 729개 × 12초 = 34,200초 = 42회 세션 = 7주.
- 비교: 주 12개 방식은 모르는 단어 3,074개에 256주.

### 8.3 기억이 상한일 때

시간으로는 하루 15개가 들어가지만, 저학년 아이가 하루 15개씩 새 단어를 계속 받으면서 통과율 85%를 유지한다는 근거는 없다. 새 단어가 많아지면 통과율이 떨어지고 복습이 불어난다. 그래서 실제 속도는 "통과율을 유지하는 하루 새 단어 수"가 정한다. 기준 시나리오에서 이 수를 고정했을 때:

| 하루 새 단어(모르는 것) | P1 (486개) | P1+P2 (2,103개) | 전체 (3,025개) |
|---:|---:|---:|---:|
| 8개 | 10주 | 44주 | 63주 |
| 10개 | 8주 | 35주 | 50주 |
| 12개 | 7주 | 29주 | 42주 |

계산: 모르는 단어 수 ÷ 하루 새 단어 ÷ 주 6일. 아는 단어 확인은 남는 시간에 들어간다(하루 10개일 때 새 단어에 524초, 나머지 286초로 아는 단어 약 24개).

카드당 시간, 통과율, 아는 비율, 하루에 감당하는 새 단어 수는 모두 가정이다. 14절의 첫 관문에서 실측해 이 표를 다시 계산한다.

### 8.4 지렛대

| 지렛대 | 효과 [estimate] | 비고 |
|---|---|---|
| 하루 새 단어 상한 | 8개 → 12개면 전체 63주 → 42주 | 통과율이 유지될 때만 |
| 오답 시 "처음으로" → "한 단계 아래로" | 복습 기댓값 8.4회 → 6.8회. 하루 복습량 약 18% 감소 | 기존 요구는 "실패 시 streak 0" |
| 아는 단어를 한 번에 걸러내는 정확도 | 잘못 "알아요"로 분류된 단어는 7일 뒤에야 드러남 | 확인 카드 비율로 조절 |
| 하루 15분 → 20분 | 기준 시나리오에서는 효과 없음(시간이 상한이 아님). 약세 시나리오에서만 의미 | 기존 요구는 15분 상한 |

## 9. 흥미와 디자인

### 9.1 카드에 얹는 게임 요소

| 장치 | 내용 | 제작 비용 | 시간 비용 |
|---|---|---|---|
| 카드 등급 | 단어 카드의 테두리가 복습 단계에 따라 바뀐다(새 카드 → 동 → 은 → 금). 금 = 익힘. 게임 상태와 기억 상태가 같은 값이다 | 테두리 4종 | 없음 |
| 도감 | DB의 주제 33개별 카드첩. 익힌 카드가 채워지고 전체가 한 화면에 보인다. 이번 주 책 카드첩은 따로 | 화면 1개 | 판 끝 10초 |
| 보스 게이지 | 한 판 = 보스 하나. 카드를 넘길 때마다 게이지가 깎이고, 확인 카드 정답은 크게 깎는다. 보스는 이모지 | 이모지 | 없음 (카드와 동시에 표시) |
| 연속 정답 | 연속 수를 화면 위에 표시. 끊겨도 벌 없음 | 없음 | 없음 |
| 번개 기록 | 1분 동안 맞힌 수의 자기 최고 기록. 남매 비교 없음 | 없음 | 1분 (복습을 겸함) |
| 주간 가족 보스 | 두 아이가 그 주에 등급을 올린 카드 수를 합쳐 잡는다 → 부모가 정한 실제 보상 | 설정 1개 | 없음 |
| 출석 | 주 5일 달성 방식. 하루 빠져도 끊기지 않음 | 없음 | 없음 |

- 확인 카드가 가장 큰 타격이라서, 모르는 단어를 "알아요"로 넘기는 것보다 정직하게 답하는 쪽이 유리하게 된다.
- 등급과 도감은 기억 상태를 그대로 보여 주는 것이라 별도의 점수·재화가 없다. 보상을 얻으려고 학습과 무관한 행동을 할 여지를 두지 않는다.
- 이 표가 실제로 흥미를 만든다는 근거는 없다. 가설이며 14절 첫 관문에서 확인한다. 3회 안에 지루해하면 보스 종류, 카드 꾸미기 순으로 더한다.

### 9.2 화면 원칙

- 한 화면에 할 일 하나. 카드 화면에는 단어, 두 버튼, 다시 듣기, 보스 게이지만 있다.
- 글자는 크게(목표 단어 56pt 이상), 버튼은 화면 아래쪽 좌우에 엄지로 닿는 크기, 가로·세로 모두 스크롤 없이 한 화면.
- "알아요" 뒤에는 탭 없이 자동으로 다음 카드. 기존 화면은 매 문항 "다음"을 눌러야 했다.
- 발음 기호는 아이 화면에 넣지 않는다.
- 화면 수는 넷이다: 오늘(3판과 도감 요약), 카드, 판 결과, 도감·부모 현황.

## 17. 게임 층: 글꼴, 지도, 보상 (2026-11-12 추가, 구현 전)

사용자 검토(시제품 화면): 글꼴이 낡아 보이고 게임 느낌이 없음. 진도를 보여 주는 지도, 갈림길 선택과 그에 따른 혜택(슈퍼마리오 3 방식), 게임 형태의 혜택을 요청.

### 17.1 지켜야 할 선

- 게임 층은 학습 규칙을 바꾸지 않는다. 어떤 혜택도 복습 일정, 카드 등급, 확인 카드 비율을 바꾸지 않는다.
- 학습을 건너뛰게 하는 혜택은 만들지 않는다(마리오 3의 P날개에 해당하는 것 없음). 갈림길은 "무엇을 먼저 하느냐"를 고르는 것이고, 안 간 길은 남는다.
- 목표 영어 단어는 글자 모양이 또렷한 글꼴로 둔다. 아이가 익혀야 하는 것이 그 글자 모양이기 때문이다. 픽셀 글꼴은 화면 틀(버튼, 숫자, 지도, 제목)에만 쓴다.

|---|---|---|---|---|
| A 픽셀 레트로 (추천) | 한글 픽셀 글꼴(Galmuri 계열) + 숫자·영문 픽셀 글꼴 | 둥근 산세리프(굵게) | 마리오 3, 지도와 한 세계로 묶임 | 작은 한글은 픽셀 글꼴에서 읽기 어려움 → 18px 미만 글은 일반 글꼴 |
| B 둥근 캐주얼 | 주아(Jua) 계열 + Fredoka | 같은 글꼴 | 듀오링고, 커비 | 지금 화면과 차이가 작음 |
| C 만화 액션 | 굵은 제목용 한글 글꼴 + 만화 영문 글꼴 | 둥근 산세리프 | 액션 게임 | 저학년에게 거칠 수 있음 |

- 글꼴 파일은 저장소에 넣어 직접 제공한다(집 Wi-Fi 안에서만 쓰므로 외부 글꼴 서버에 의존하지 않음). 후보 글꼴은 공개 라이선스(OFL)로 알고 있으나 [recall] 이번에 확인하지 않았다. 구현할 때 배포 패키지의 라이선스 파일을 읽어 확인하고 `cards/fonts/`에 함께 둔다.
- 보스와 지도 아이콘은 이모지를 작은 캔버스에 그린 뒤 보간 없이 확대해 픽셀 그림처럼 보이게 한다. 새 그림을 그리지 않는다. 기기마다 모양이 다를 수 있어 구현 뒤 화면으로 확인한다.

### 17.3 지도

구조: 세계 하나 = 단어 묶음 하나(시제품은 60단어 세계 1개, 본 프로그램은 대역별로 150~200단어씩). 칸 하나 = 한 판.

| 칸 종류 | 내용 | 혜택 |
|---|---|---|
| 길 칸 | 새 카드 7~9장 + 그날 만기 복습 일부. 갈림길마다 주제가 다름(시제품: 물건·자연 길, 행동 길, 느낌·모양 길) | 별, 처음 깬 칸은 지도에 깃발 |
| 복습 몬스터 | 만기 복습이 8장 이상 쌓이면 지도 위에 나타나 길을 막는다. 복습만 하는 판 | 별 2배, 아이템 1개 |
| 보너스 집 | 번개 라운드 1분(익은 단어 맞다/아니다) | 아이템 1개 |
| 성 | 그 세계 단어의 확인 카드만 나오는 판. 세 길 중 두 길을 깨면 열림 | 열쇠(다음 세계), 금 테두리 깃발 |

- 갈림길: 시작 → 세 길로 갈라짐 → 성. 두 길만 깨도 성에 갈 수 있고, 남은 길은 "보너스 길"로 남아 별을 2배로 준다. 세계 완성(왕관)은 모든 칸을 깨야 한다.
- 복습 몬스터는 마리오 3의 지도 위 적에 해당한다. 복습이 밀리면 아이가 고르지 않아도 지도에서 먼저 처리하게 되므로, 길 선택이 복습을 미루는 수단이 되지 않는다.
- 칸은 하루에 여러 개 갈 수 있지만 같은 단어는 하루 한 번만 채점된다(기존 규칙).
- 지도는 진도 화면을 겸한다. 깬 칸, 현재 위치, 남은 칸, 세계별 금·은·동 수가 한 화면에 보인다. 카드첩은 지도에서 들어간다.

### 17.4 혜택

| 혜택 | 얻는 법 | 효과 | 학습에 주는 영향 |
|---|---|---|---|
| 별 | 확인 카드 정답 3개, 일반 카드 1개, 보너스 길·몬스터는 2배 | 꾸미기 상점의 화폐, 주간 가족 상자에 합산 | 없음. 확인 정답이 가장 많이 줘서 정직한 답이 유리 |
| 방패 버섯 | 몬스터, 보너스 집 | 확인 카드를 한 번 틀려도 연속 정답이 안 끊김 | 없음(틀린 단어는 그대로 배우는 단어가 됨) |
| 불꽃 꽃 | 몬스터, 보너스 집 | 한 판 동안 보스에게 주는 타격 2배 | 없음 |
| 망치 | 성 | 지도에서 막힌 바위를 깨 지름길을 엶(순서만 바뀜) | 없음 |
| 꾸미기 | 별로 구입 | 캐릭터 모자, 카드 뒷면 무늬, 지도 깃발 색 | 없음 |
| 열쇠 | 성 | 다음 세계 | 진도 관문. 성은 확인 카드라 실제로 아는지 본다 |
| 가족 상자 | 두 아이의 주간 별 합계 | 부모가 정한 실제 보상 | 없음. 아이별 비교 없이 합계만 표시 |

- 넣지 않는 것: 판 건너뛰기, 복습 면제, 뜻 미리 보기 같은 혜택. 학습을 줄이는 방향이기 때문이다.
- 아이템은 판 시작 전에 고르는 한 칸짜리 가방으로 둔다. 판 중간에 고르는 화면은 시간을 쓴다.

### 17.5 시제품에 넣을 범위

1. 글꼴 A안 적용 (`cards/css/app.css`, `cards/fonts/`).
2. 지도 화면: 세계 1개, 길 3개(각 2칸) + 복습 몬스터 + 보너스 집 + 성. "오늘" 화면을 지도로 바꾼다. 칸을 누르면 그 칸의 판이 시작된다 (`cards/js/map.js` 신규, `cards/js/main.js`, `tools/make_cards_demo.py`에 칸 배정 추가).
3. 별, 방패 버섯, 불꽃 꽃, 한 칸 가방. 꾸미기 상점과 가족 상자, 망치는 다음 단계.
4. 번개 라운드(보너스 집).
5. 카드 규칙(`cards/js/deck.js`)은 칸이 정한 단어 목록을 받는 것 외에는 바꾸지 않는다. 기존 카드 테스트가 그대로 통과해야 한다.

미정: 한 세계의 크기, 길 이름과 주제 배정은 60단어로 아이들이 써 본 뒤 정한다. 이 설계가 재미를 만든다는 근거는 없다.
