# 세계 데이터 계약 v2 — 연결 지도

상태: **연결망 보완 요청 반영, 실제 어휘 생성기·게임 연결 전**. 2026-11-12 사용자가 독립 루트 문제를 지적하고 연결망 보완을 요청했다. v1의 독립 품사 길과 `castleNeeds=2`를 그래프 계약으로 대체한다. 전체 세계관·표현 학습·대륙 성의 미결 승인을 일괄 승인한 것으로 해석하지 않는다.

이야기는 [WORLD_BIBLE.md](WORLD_BIBLE.md), 경로 전수 검사는 [world_map_routes.md](research/world_map_routes.md). `tools/preview_world_maps.py`는 **단어 ID 배정 없이 칸 수·연결·카드 수 목표만 만드는 시안 도구**다. `cards/data/worlds.json`은 아직 만들지 않는다.

## 1. 확인한 원본과 범위

[verified] `reference/weekly-tool/vocabulary.json`의 SHA-256은 `38b97c372feb8585eed6b9458194294039b4f8a62990ed44b6dfffb91e123130`이다. `stats.source_sha256`는 이전 입력 자료의 값이므로 현재 파일 해시 대신 쓰지 않는다.

대상 집합은 `lemmas[].track in {vocab,sight}`와 `old_priority in {P1,P2,P3}`의 교집합이다. 각 표제어에 `cards[].lemma_link=lemma.id`, `kind=기본`, `sense_order=1`인 카드 한 장을 연결한다. 현재 4,610개 모두 하나씩 연결된다. ID는 철자나 배열 위치로 재생성하지 않고 원본 `card_id`를 그대로 쓴다.

|---|---:|---:|---:|
| P1 | 1,094 | 121 | 1,215 |
| P2 | 2,310 | 0 | 2,310 |

교과 보류 57개, band 없는 패턴 4개, 과거형·감정 파생형·추가 뜻은 별도 범위다. `defer=true`만으로 제외하지 않는다. 학습 범위는 track/band로 결정하고 추가 제외는 검토 기록을 남긴다. 부모 승인 대표 뜻 교체는 `lemma_id → card_id`의 별도 override와 근거로 적용하며 같은 표제어를 중복 배정하지 않는다.

## 2. 버전과 최상위

UTF-8 JSON. 최상위는 `schemaVersion=2`, `contentVersion`, `status(draft|ready)`, `source{path,sha256,selection,overrideVersion}`, `counts{lemmas,cards,continents,worlds,byBand}`, `continents[]`다. 완성본 개수는 카드=표제어=4,610, 대륙=3, 세계=30이며 부분 fixture는 실제 부분 개수를 쓴다.

대륙 필드는 `id,band,name,story,worlds,finale`. P1→P2→P3, 세계 8/15/7개의 순서는 유지한다. 이름·색·문구 변경에도 발행된 ID는 유지하고 배열 순서나 철자를 키로 쓰지 않는다. 문구는 HTML 없는 일반 문자열, 색은 `#RRGGBB`다. 지원하지 않는 버전은 명시적으로 중단한다.

## 3. World — 표시는 보존, 이동은 그래프로

| 필드 | 계약 |
|---|---|
| `id,name,title,concept` | name=title, 기존 표시 필드 유지. |
| `palette{sky,ground,path}` | 길/땅 명암비 3:1 이상, 실제 글자·노드·기기 검증 별도. |
| `bossEmoji[],castle{name,emoji},key{name,emoji}` | 보스 6개 이상, 세계 간 중복 없음. 보상은 학습 일정·등급에 영향 없음. |
| `intro,outro,story` | 입장·성 통과·다음 이동 문구, 각각 두 문장 이내. |
| `nextWorldId,status` | 대륙 내 다음 세계 또는 null, draft/ready. |
| `routes[]` | `{id,name,icon}` 세 가지 장소 분위기. 품사 길·완료 조건이 아니며 어휘를 소유하지 않는다. |
| `map` | 아래 연결 그래프. **이동·해제 조건의 유일한 원본**. |
| `castleRule` | `{type:"reach", nodeId:castleNodeId, cards:12, passRate:0.8}`. |
| `sideActivities[]` | 기능어·잔여 표현 집. 왕관의 필수 대상. |

v1의 `roads[].tiles[].words`와 `castleNeeds`는 v2에서 쓰지 않는다. 이 전환은 v1과 **호환되지 않으므로 schemaVersion을 올린다**. v1 데이터를 숨겨 변환하거나 `castleNeeds=2`를 남겨 로더가 잘못 해석하게 하지 않는다. 현재 게임은 여전히 v1이며 Claude가 v2 로더·규칙을 별도로 연결해야 한다.

### map

| 필드 | 계약 |
|---|---|
| `startNodeId,castleNodeId` | 전역 고유 노드 ID 참조. |
| `stages` | 학습 구간 수 K. 현재 세계는 5 또는 6. |
| `nodes[]` | 아래 Node, 시작·성·합류점과 모든 학습 칸 포함. |
| `edges[]` | `{from,to}`. 무방향 이동, 중복·자기 연결 금지. 모든 선의 실제 만나는 지점은 명시적 노드다. |

Node 공통 필드: `id,kind,x,y`. 좌표는 viewBox 0~1000 / 0~490의 표시 좌표이며 이동 규칙에 쓰지 않는다. kind는 `start`, `tile`, `junction`, `plaza`, `castle`이다. tile만 `stage(1..K),lane(0..2),words:[card_id...]`를 가진다. 한 칸 1~10개, 모든 칸과 필수 집을 합쳐 대표 card_id가 정확히 한 번씩 나온다. 합류점·광장에는 words가 없고 시험·별·채점도 없다.

### 연결과 비용 균형

- 각 구간에 세 개의 학습 칸을 놓고, 구간 앞 합류점→각 학습 칸→구간 뒤 합류점으로 잇는다. 구간마다 다시 세 방향을 고를 수 있다. 중간 합류점 하나는 광장으로 표시하고, 나머지는 작은 원으로 그린다. 광장은 무료 이동 지점이다.
- 시작점은 첫 합류점, 성은 마지막 합류점 역할이다. 중간의 다른 길로 갈아탈 때 추가 카드·별·열쇠를 요구하지 않는다.
- N개 주 지도 카드의 초기 배정 목표: `K=ceil(N/30)`, 총 3K칸. `q,r=divmod(N,3K)` 후 앞에서부터 **구간 우선·그다음 lane 순**으로 r칸에 q+1장, 나머지에 q장. 여분이 있는 혼합 크기 구간은 최대 하나이므로 어떤 단순 시작→성 경로도 K칸, 카드 수 차이는 최대 1장이다.
- 빈도순은 세계 멤버를 정한다. 세계 내부에서는 품사를 섞고 주제를 분산하며 충돌 단어를 다른 칸에 놓는다. 품사별 이름·행동·꾸밈 독립 길이나 mixed 예외는 더 이상 필요 없다. 기존 POS 감사는 이전 안이 쏠렸다는 근거로만 보존한다.
- 이 수식은 **카드 수 목표**다. 실제 ID를 배정한 뒤 동일 뜻·확인된 동음·유사어를 분리하면서도 모든 단순 경로의 카드 수 차이를 1 이하로 유지해야 한다. 불가능하면 K 증가나 세계 크기 조정안을 보고하고 draft로 둔다. 조용히 균형·분리·범위를 깨지 않는다.
- 경로 비용은 처음 만나는 대표 카드의 수다. 이미 아는 카드·재도전·복습·박쥐 시험·성 12장은 실제 플레이 시간에 영향을 주므로 총 시간의 동일함을 보장하지 않는다.

## 4. 이동·해제·재방문

**진행은 ‘길 두 개 완료’가 아니라 실제로 성에 닿음으로 판단한다.** 데이터에 선만 연결하고 모든 후반 칸을 바로 여는 구현은 허용하지 않는다.

1. 시작점에서 출발해 완료한 tile과 무료 junction/plaza만 통과하는 BFS로 도달 집합을 계산한다. 미완료 tile은 통과할 수 없고 그 앞에서 멈춘다. frontier에 있는 미완료 tile만 시작할 수 있다. 그래프가 유효하면 후반 구간까지 바로 갈 수 없다.
2. 기존의 카드 첫 만남 완료 기준을 충족하면 칸을 완료한다. 오디오 실패·판 중단으로 끝내지 못한 칸은 그 다음 합류점으로 이동할 수 없다. 단순히 버튼을 눌렀다는 이유로 완료하지 않는다. 미리보기의 클릭 완료는 경로 체험 전용이다.
3. 완료한 칸은 다시 풀지 않고 양방향으로 통과할 수 있다. 이전 구간의 미완료 선택지에도 다시 접근할 수 있고, 한 번 고른 길에 묶이지 않는다. 무료 이동이 복습 완료·별·게이지 변동을 만들지는 않는다.
4. 마지막 합류점(성)에 도달하면 세계 성 12장·80% 시험을 시작할 수 있다. 각 구간 최소 한 칸 완료는 **그래프 구조의 결과**이며 별도 점수 누적·두 길 판정이 아니다. 데이터 검사도 모든 성 경로가 각 구간을 지나가는지 확인한다.
5. 성 통과는 다음 세계 해제, 남은 모든 칸+필수 집+성 통과는 세계 왕관이다. 남은 칸의 기존 보너스 보상은 성 통과 뒤에만 적용하며 학습 규칙은 같다. 세계의 카드첩에는 `만남 x/N`도 표시해 성 통과가 전체 학습 완료처럼 보이지 않게 한다.
6. 복습 몬스터는 선택, 박쥐 게이지가 가득 찼을 때만 기존 박쥐 시험이 새 판보다 우선한다. 길 연결이나 무료 이동으로 박쥐 시험을 우회하지 않는다.
7. 한 아이의 위치·완료 칸·열쇠는 독립 저장한다. 지도 이동에 다른 아이의 완료 여부를 요구하지 않는다.

### 대표 세계 p1-01

주 지도 142장 → 5구간 × 3선택 = 15칸. 첫 두 구간은 각각 10/10/10장, 셋째는 10/9/9장, 나머지 두 구간은 각각 9/9/9장이다. 성까지 모든 경로는 5칸·47~48장이다. 맨 위로 출발해 다음 구간 맨 아래로 바꿔도 추가 카드가 없다. 나머지 94~95장은 사라지지 않고 재방문 대상이다. 기능어 집 16장은 별도 필수 대상이므로 전체 배정은 158장이다. 성 시험과 대륙 완료는 다르다.

## 5. 필수 집과 표현

Activity는 `id,name,icon,kind(sight|phrase),requiredForCrown=true,tiles[{id,words}],status`다. 시작점 또는 광장에 `anchorNodeId`로 붙이고, 해당 지점 도달 뒤 방문할 수 있다. 교차로 지름길·성 필수 경로로 취급하지 않는다. P1 기능어 121개는 8세계의 집에 16/15/.../15장, P3 마지막 두 세계 표현은 한 장씩이다.

표현은 대역을 유지하고 전체를 하나의 어휘로 학습하며 구성어 선행 관문을 없애자는 이전 제안은 그대로 **미승인**이다. 선택적 `componentHints:[{token,candidateCardIds,status}]`는 부모용 참고이며 해제에 쓰지 않는다. 기능어의 빈 뜻을 정답으로 만들지 않는다. 표현·기능어 지원과 검수 전에는 draft이며, 집을 생략해 전체 완료로 표시하지 않는다.

## 7. 생성기와 검증 (실제 ID 배정은 후속)

선정 범위·원본 해시는 1절을 따른다. 각 대역 안 일반 어휘·표현·기능어를 나누고 WORLD_BIBLE 수량대로 세계 슬롯을 채운다. 트랙 안 빈도순은 NDL→NGSL→Cambridge Starters/Movers/Flyers→무근거 순이다. 같은 단계의 수치가 같으면 다음 근거와 lemma_id로 결정한다. 무근거 집단은 theme 오름차순 큐를 한 개씩 순환하고 각 큐는 lemma_id순이다. 동일 입력·override·설계 버전이면 같은 결과여야 한다.

검사 목록:

- 전체 대표 card_id 합집합이 선정 집합과 정확히 같음, 중복·누락·잘못된 대역 없음. 모든 tiles는 map.nodes와 필수 집에만 한 번 존재.
- 단일 시작·성, 유효한 edge 참조와 좌표, 빈 학습 칸·고립 노드·지름길 없음. 모든 학습 칸이 어떤 출발→성 경로에 포함됨. 모든 완료 후에는 전체 노드 접근 가능.
- 실제 그래프에서 모든 단순 시작→성 경로를 열거해 각 stage를 정확히 한 번 지남, K칸, 최대/최소 카드 차이≤1임을 확인. 무료 노드만으로 성 도달 불가. 비용은 `words.length`로 재계산하고 별도의 cardCount를 신뢰하지 않음.
- 같은 한글 뜻은 NFC·공백 정규화로 비교. 빈 뜻끼리는 묶지 않음. 검토한 유사어·동음 묶음은 같은 칸에서 제외하고 확인 카드 오답 보기에서도 제외.
- palette 대비, 문구 길이, 보스 비중복, 음원·표현·기능어 지원 상태. 의미·발음·iPad 렌더링은 사람 검토 필요.

시안 도구 출력의 `cardCount`는 이 마지막 words 배정이 없는 설계 목표이며 `map.version=2`도 시안 내부 식별자다. 이를 배포 `worlds.json`으로 로딩하지 않는다. 실제 schemaVersion=2 출력은 위 필드 계약과 `words`를 사용해야 한다.

## 8. 대륙 성과 저장·화면 연결 요청

대륙 성은 각 세계의 모든 칸·필수 집·세계 성 완료 뒤 왕관을 모으면 열린다. 제안된 40장·80%는 아직 미승인이다. 이미 만난 대륙 카드만 중복 없이 세계별로 고르게 뽑고, 문항은 카드의 지원된 형식을 따른다. 시험 계획과 중단 상태를 저장하고 재접속으로 표본을 바꾸지 않는다. 실패해도 완료 칸·왕관·열쇠를 빼앗지 않는다. 일정·등급 갱신은 기존 학습 엔진만 담당한다.

Claude 연결 요청:

- 고정 POS/LINES와 roadDone/castleNeeds를 v2 그래프·도달 집합·성 reach 판정으로 교체한다. 좌표로 접근성을 판정하지 않는다.
- 무료 이동, 이전 구간 재방문, 박쥐 우선, 남은 카드 수, 12장 성 출제를 연결한다. 성 풀은 해당 세계에서 만난 카드로 제한하고 일반 복습은 전체에서 유지한다.
- 전체 카드 카탈로그·음원 연결은 별도다. 세계별 완료 노드·성·왕관·획득 열쇠는 `profile.map.worlds[worldId]`, 대륙 시험은 `map.continents[continentId]`, 별·가방·박쥐는 프로필 공통으로 저장하는 안을 권장한다. 두 기기 병합에서 보상 중복 지급·다른 세계 성 복사를 막는다.
- 시제품 w1 기록은 card_id로 보존하며 새 지도에 자동으로 성·열쇠를 복사하지 않는다. 구체 마이그레이션은 구현 전에 검토한다. 승인된 graph node ID를 새 배정에 재사용할 때는 내용 변경과 진도 매핑을 명시한다.

이번 작업은 연결 설계와 실제 클릭 가능한 경로 시안까지다. 기존 `cards/js/*`, `cards/css/*`, `tests/*`는 상대 담당 범위라 직접 수정하지 않고 요청으로 남긴다.
