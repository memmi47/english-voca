## 바꿀 수 없는 조건

- 답을 먼저 보여 주지 않고 기억에서 꺼내게 한다. 빈칸 문항의 문장 음성은 답한 뒤에만.
- 학습 단어가 나올 때마다 미국식 발음 자동 재생, 다시 듣기, 중복 방지, 실패 시 문항 유지와 재시도. 소리 없이 완료 처리 금지.
- 복습 1·3·7·14·30일 (T1·T2만), T3는 노출만. 같은 카드는 하루 1회 채점. 카드의 depth_target까지만.
- 하루 15분 상한. 남매 기록 분리, 점수 비교 화면 금지(협동 목표는 가능).
- 힌트 후 성공, 독립 정답, 게임 보상을 구분해 기록. 게임 결과는 소리 도움 결과로 표시.
- 개발용 합성 음원을 검수 완료로 표시하지 않는다. 원본 `reference/` 파일은 수정하지 않는다.
- 유사어는 처음 만날 때 다른 장면에 배치. 동음 쌍은 소리 기반 보기에서 서로 제외.

## 설계 판단의 근거로 남기는 점검 결과

- 그 주 책 단어가 우선이다. 복습은 사이사이에 넣고, 시간이 모자라면 복습 꼬리를 자른다. (구현됨, `session.js`)
- 읽기 지식(앎/모름)은 depth 1~2에서 판정한다. depth 3~4 오답은 읽기 지식을 되돌리지 않는다 (`srs.js`).
- 게임성이 커질수록 15분이 놀이에 쓰일 위험이 있다. 분당 인출 횟수를 설계 판단 기준으로 쓴다. 사건 접수 화면과 보고서가 여기에 해당하며 실측 전이다.
- 그림은 직접 그린 SVG 9개뿐이다. 그림 제작 비용이 사건을 늘릴 때의 주요 제약이다.
