# 다음 세션 인계: 탐정·방탈출형 구현

새 세션은 이 파일을 먼저 읽고 시작한다. 모델은 Fable 권장(콘셉트·학습 설계 판단이 핵심).

## 시작 문장 (새 세션에 그대로 붙여넣기)

> `docs/NEXT_SESSION.md`, `docs/DESIGN.md`, `docs/TEST_REPORT.md`를 읽고, 인계 문서의 계획 1~4를 순서대로 진행해 줘. 2단계 설계안 비교가 끝나면 구현 전에 선택안을 나에게 보여 줘.

## 현재 상태 (브랜치 `claude/clever-planck-grh0sn`, PR #1)

- 동작하는 것: 두 프로필, 팩 가져오기(주간 도구 export 형식), 장면 학습 → 인출 → 오답 재도전 → 복습 저장, 15분 상한, 음성 재생·실패 복구, Mac 서버 보관 사본과 동기화.
- 테스트: 단위 30건 `node --test tests/*.test.mjs`, 통합 42건 `node tests/e2e.cjs`. 모두 통과 상태에서 시작한다.
- 실행: `python3 tools/serve.py` → http://127.0.0.1:8077 → 부모 메뉴 → 데모 팩.
- 미테스트: iPad 실기기 전부, 실제 책 표본, 사람이 검수한 음원.

## 계획 (사용자 승인됨)

1. 채점·복습 규칙을 `game/js/session.js`의 퀴즈 진행 코드에서 분리한다. 목표 API: 오늘의 카드 계획, 도입 기록, 인출 시도 기록(카드, depth, 정오, 힌트, 청취 여부) → 일정 갱신. 기존 테스트가 그대로 통과해야 한다.
2. 탐정·방탈출형 설계안 2~3개를 비교해 하나를 고른다. 사건 하나 = 주간 팩 하나. 단서 찾기·증언 맞추기·암호 풀기 등을 depth 1~4에 대응. 선택안은 구현 전에 사용자에게 보인다.
3. 데모 팩으로 "유령의 집 사건" 한 편을 끝까지 플레이 가능하게 만든다.
4. 새 화면용 테스트와 iPad 실기기 확인 목록을 추가한다.

## 바꿀 수 없는 조건

- 답을 먼저 보여 주지 않고 기억에서 꺼내게 한다. 빈칸 문항의 문장 음성은 답한 뒤에만.
- 학습 단어가 나올 때마다 미국식 발음 자동 재생, 다시 듣기, 중복 방지, 실패 시 문항 유지와 재시도. 소리 없이 완료 처리 금지.
- 복습 1·3·7·14·30일 (T1·T2만), T3는 노출만. 같은 카드는 하루 1회 채점. 카드의 depth_target까지만.
- 하루 15분 상한. 남매 기록 분리, 점수 비교 화면 금지(협동 목표는 가능).
- 힌트 후 성공, 독립 정답, 게임 보상을 구분해 기록. 게임 결과는 소리 도움 결과로 표시.
- 개발용 합성 음원을 검수 완료로 표시하지 않는다. 원본 `reference/` 파일은 수정하지 않는다.
- 유사어는 처음 만날 때 다른 장면에 배치. 동음 쌍은 소리 기반 보기에서 서로 제외.

## 새 설계에 반영할 점검 결과

- 그 주 책 단어가 우선이다. 복습은 사이사이에 넣고, 시간이 모자라면 복습 꼬리를 자른다.
- 읽기 지식(앎/모름)은 depth 1~2에서 판정한다. depth 3~4 오답은 읽기 지식을 되돌리지 않는다 (`srs.js`).
- 게임성이 커질수록 15분이 놀이에 쓰일 위험이 있다. 1분당 인출 횟수를 설계안 비교 기준에 넣는다.
- 그림은 직접 그린 SVG 9개뿐이다. 그림 제작 비용이 설계안의 주요 제약이다.
- `game/js/main.js`의 퀴즈 화면(학습·문항·종료 화면)은 교체 대상이다. 저장(`store.js`, `sync.js`), 음성(`audio.js`), 규칙(`srs.js`), 가져오기는 유지한다.

## 비용 규칙

- Firecrawl 등 유료 크레딧 도구는 사용자 승인 없이 쓰지 않는다. 하위 에이전트에도 같은 제한을 명시한다.
- 파일 4개 이상을 건드리는 변경은 3~5줄 계획을 먼저 보인다.
- 토큰이 부족해 중단이 예상되면 시작하지 말고 알린다.

## 사용자 쪽에서 진행 중이거나 필요한 입력

- iPad 실기기 확인 (`docs/TEST_REPORT.md` 미테스트 목록).
- 학원 책 표본 15~20쪽 또는 책 목록.
- 사람이 검수할 음원 (부모 녹음 또는 라이선스 확인된 TTS).
